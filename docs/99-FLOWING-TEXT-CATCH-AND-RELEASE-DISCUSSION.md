# 99 — 流过、留住、探索或放回：文字流模式讨论

2026-10-05（UTC+8），接98。Henry本轮仍明确讨论、不是指定河流/瀑布或授权立即实现。开始检查干净`b9903df`。本轮不安装Pretext/开发新renderer/算新算法/改数据或发布。

## 用户纠正与启发

Henry认为现有“随机一句/下一句”体验已好：用户无需选择接续候选。98随机漫步与它核心重复，强制自己挑下一句可能增加选择困难与心理负担；不必改造成随机漫步。这是Henry的产品判断/担忧，不记为独立新用户试验结果。现有主入口保留，随机漫步不再作新模式核心，湖泊+强制关联接续也不沿用为当前共识。

用户关注文字流动、感兴趣时抓出并稍固定、其余继续流、可深入探索或放回看下一处；河流/瀑布是灵感，强调仍讨论且希望更妙/有灵性的idea，不是最终选型。

## 共同问题与Agent提案（未确认）

核心状态为**流过→留住→探索或放回**。默认不操作也有下一处经过，不出现必须选择才能前进的路口。不需要另造推荐系统：内容抽取可延续已有按书公平/真实划线规则；区别应来自观看/停驻/复流体验，不是把“下一句”改自动播放就称新世界。每个流动单元是一处完整真实划线的字行组合，长文可诚实摘录预览；字/句不跨出处混拼，ID/原顺序/全文/来源/全部Tag保留。文字就是材料，不另造水面、岸、漂流瓶或作者故事。

### 1. 如何流动

候选A为慢的、宽的文字流：几组水平可读字行沿一个轻弯/斜向路径经过画面。不是文字旋转成水花或全部4,663段同时漂；一处主要清楚、另一些正在来/离开，有疏密和前后层次，不同段不必同速，但同段整体协调。当前阅读区域速度较缓；短时局部散字可为反馈，不能破坏正文辨认。

初稿只作为模式设想，方向/路径/速度/字号/颜色/可见数量未定，不要求Henry凭空选择。自动流动不能制造“错过就没了”的考试感：可一键回看刚才一处，长文不用在流中读完，失去页面可见性应停止推进；全局暂停与reduced-motion的静态降级保留。

### 2. 留住的动作

主要以轻点/点击留住整段，不强迫拖到岸边或抓住单个逃逸字符；鼠标靠近可局部缓一下，手机不依赖hover。保留稳定可点区域，不靠追逐完成阅读。

留住后这一段安定、原处/附近舒展开成完整阅读位置，其他字流让出空白并继续通过；不穿过正文，也不需要正文另躲进侧边旧卡片。流的速度/对比/密度可降低避免抢阅读注意。所谓“固定一段时间”更宜是**读者正在读的时间**，不设置十秒自动冲走；明确放回/换读才能结束停驻。一次只留一处作为主阅读，不做卡片收藏板；点击另一处可让它接手、上一处自然放回。

### 3. 放回与探索

- 放回：原段完整地回到流动状态，不混拼/分解成伪原文，继续旁观无需再点“下一句”。刚放走/错过的一处可简单回看，不把回看变成必须选的候选矩阵。
- 探索：不展开一圈让用户反复选。可利用已有书房/主题入口，或一项可选“沿这一处流一会儿”：读者主动决定后才临时改流的内容范围，围绕明确真实书/Tag/实际模型候选，自己仍可旁观其内容经过。保留所选原文/实际来路与“一步回到全部”，不把随机补位称关联/观点一致。具体取范围/如何选择尚未定，不修改Tag或让几何暗示语义。

## 除河流/瀑布外的两个节奏候选

1. **潮汐/呼吸式来临**：不是匀速不停冲过，而是出现—稍留—离开，留出清楚的观看时段；触碰可延长停驻。仍不要求选择才继续。这里强调时间节奏，不建设海水场景。
2. **由人拨动的流**：平时安定，划一下/拨一下文字流动一阵，松手逐渐减速，再碰即可留住。读者决定运动的时机，不必追赶自动流；它也可能太接近普通滚动，需靠整体排版/抓放反馈才成立，未声称更优。

Agent目前偏**有节奏的慢流，停驻时安稳，放手复流**，而不是喷涌瀑布或全天漂浮字粒子。灵性来自简单、可预期的回应：想看它会等，放手它离开，错过能回来，不靠AI猜心情/遥测。此倾向未获Henry确认，不是新的强制动作规格/三套模式施工。
