## 完成范围

1. 先复现并修复地图详情抵达问题：改前 390px 区域列表与 320px 最长原文直达都不能把详情标题焦点交给阅读面。改后列表与Canvas点选进入，立即显示原文开头并把焦点给标题；关闭/Back回到仍在DOM内的来源元素及离开时的滚动位置，来源卸载则退回Canvas。直接访问 `?h=` 经room-memory复位后仍能看见文字。
2. 地图房间及页面外壳使用全深色：深墨绿色真实地形与略暖的深灰阅读面，不做深图白纸硬切。桌面在地图右侧展开全文；1049px及以下保持地图片段在上、全文在下，进入时滚至能看到正文起始的位置。标题焦点是细下划线而不是输入框样式。
3. Canvas只调整原有密度、网格、等高线、点与真实标签的绘制色和透明度，**不移动点、不重跑布局、不增加伪造边界**；531点的亮书在世界尺度缩小且半透明，放大后恢复单点强调。高密度不再合成一整块实心色域。当前详情的Book Aura从该划线所属的真实书封取，而非书籍选择器当前书封；主题标签仍无语义色。
4. 其他房间沿用7A浅色。分享内容与独立卡片调色不变；地图内打开的分享浮层沿用深色环境，手工复制文本框也保持对比。public空快照下仍展示诚实空状态。

## 视觉判断与未验收

- 同色域在手机上比E的深图白文没有断层；390详情入场能看到来源、完整引文开头和一小段地图。1440是并页，320长文完整展开、标签及出口仍可访问。深色地图已更像地形而非通用星点卡，但它是否**足够有作品感**以及长时深底中文阅读是否舒适，应由用户在真实交互中判断；工程通过不是视觉Gate。
- 手机世界页首屏仍有不少导航和工具，地图完整轮廓要向下滚动才可见；不为了伪造“惊艳首屏”移动真实点或换挑选过的句子。Safari、真实手机、真实浏览器200%与读屏/长期阅读舒适度未验证；Chromium键盘和720×450等价视口不能冒充这些环境。
