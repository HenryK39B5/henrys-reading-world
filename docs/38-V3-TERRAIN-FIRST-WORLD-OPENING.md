# 38 — Batch 7E：真实地形开场试验

> 日期：2026-09-23
>
> 状态：7E局部构图试验已在本机产品实现并拍摄；视觉Gate待用户判断。不等于全站深色Gate通过。

## 目标与边界

用户认可深色地图但希望更有视觉冲击。7D细节打磨后，首选 `docs/37` 的「地形开场」方案：让真实地图成为进入世界总览时的主画幅，减少其作为普通房间内嵌工具的感觉。仍保留六个导航入口、缩放、书籍选择、真实标签点击、区域列表和键盘路线；不默认精选划线、不移动点、不重跑UMAP、不制造海岸线或新数据。仅影响 `/map` 和 `/map?book=…` 的**世界总览**；区域/详情保留7D阅读关系。

## 实施

- 世界总览加专用 `map-opening-world` 状态；标题更明确，但不是覆盖地形的营销hero。世界顶部重复的「小径列表」出口移除，六入口导航与底部小径入口仍在；区域/详情保留该顶部出口。
- 桌面地图最大画幅1360px，超出1160px文字版心；手机地图横向到屏幕边缘，仍让下方语义区域列表自然出现。缩放和书籍选择继续位于地图之前，保证可达性，手机一排44px工具。
- `MapCanvas`仍用相同viewport与单Canvas，所有真实点/标签坐标不变；选书仍只点亮该书的真实点。桌面与移动只改变Canvas容器宽高和周边边框。

## 同一数据证据

前一版：`.private/review/v3-private-atlas/dark-cross-page/after/{desktop,mobile,narrow}-world.png`、对应 `*-lit.png` 和 `*-map-in-view.png`；本轮：同根目录 `7e/`，同一 `e2e/capture-7d.spec.ts` 脚本以 `CAPTURE_PHASE=7e` 拍摄。保留真实 `b-013`、`h-013`、`h-231`、1440×900/390×844/320×720；额外26张本机PNG。map SHA-256 `567534bf71bfc5f6266ceb8ecd26267c4399888d87a1d606fed784a03d9fcd9e`，4,663点、56标签锚点。对照不是改坐标/换文本的效果图。

人工检查：390px地形不再被20px内边距裁成一个图框，真实点群的轮廓更早出现在首屏；桌面地图拥有比导航/标题更强的面积权重。320px去掉重复出口后也能看到更完整的地形，并非缩小的1440版。当前仍有标题和工具在地形之前，尚未达到完全沉浸式开场；不为视觉效果牺牲导航或把控件叠在Canvas标签上。它是一版供真实体验的构图候选，**不宣称已足够惊艳**。

## 验收与后续

新增回归断言世界总览在390px全幅、原始地图缩放、语义区域入口与320px无横溢；区域和详情均不能套用世界开场。地图入口/键盘/分享等旧行为照常回归。测试命令及实况记在 `docs/08`。

下一轮如果这版方向成立，再在同一地图坐标下进一步比较地形首屏的信息密度与文字标题位置，然后把跨页深色规则带到**门厅、书房、小径和目录**做同一轮跨页测试；不把当前浅色房间直接称为最终方案，也不无Gate地一键反色。发布仍需单独批准。
