## 首次访客任务卡

这份任务卡给第一次看到产品的人，**不要先解释导航名称或地图操作**。观察者只记录犹豫、误点、回退、无法判断下一步和“以为会发生但没有发生”的地方；不主动教操作，除非对方卡住超过约30秒。任务使用本机真实 World，不要求公开数据。

1. 从首页开始，找到一处你愿意继续读的划线，并说出它来自哪本书。
2. 打开这本书，看另一处真实划线，然后回到刚才的位置。
3. 从地图找到一个主题区域，打开其中一处划线，并说明你现在处在世界的哪一层。
4. 从这处划线继续走一条主题小径，读完一处后返回地图。
5. 分享当前这处划线，检查分享内容是否仍是刚才读到的原文和出处，然后关闭分享。
6. 不使用鼠标完成一次：打开地图、进入划线、回到来源位置。

## 本机结果

新增 `e2e/audit-7h.spec.ts` 与 `playwright.audit-7h.config.ts`。在 320、390、720、1440 CSS px 的真实 local snapshot 页面上检查 10 条关键路线，共采集 **239 个文字样本**：最低对比度不低于 4.5，所有样本无横向溢出；亮书来源名使用 Canvas 颜色读回，避免把 Chromium 的 `color(srgb ...)` 序列化误判为黑色。

在 390px 的首页、所有书、主题小径、地图和地图详情上遍历键盘焦点。真实交互焦点均有名称、未落入 `aria-hidden` 子树且有可见焦点；Tab 走完页面后落到 `body` 的浏览器终点被排除，不算产品控件。地图详情的标题抵达、语义列表、分享和书籍选择器沿用已有专项测试。

本机探测了 Chromium 的 `Ctrl+=`：无头与有窗口模式下 `innerWidth`、DPR 和 `visualViewport.scale` 均不变，不能证明菜单式页面缩放。因此保留两类不同证据：720×450 的200%等价重排与 CDP 2×视觉放大继续由 `e2e/zoom.spec.ts` 验证；真正浏览器菜单200%列为人工未验证。
