# R3-A：独立观察窗口的对齐、方向感与稳定性

日期：2026-09-26
状态：R3-A 与 R3-B 完成；未选择生产算法。R2-A 见 `57`，R2-B 见 `58`。

## 研究问题

不同投影窗口是否可以保留同一批点的方向感，同时允许局部结构变化？本轮只比较独立布局的几何关系，不把对齐后的图解释为语义真值，也不实现 AlignedUMAP 或产品切换。

## 固定输入与流程

使用公开 snapshot 3,462 条、同一 1,024 维本机向量和 R2-A 已验证的公开 hash。比较：

- RP96：生产 `projectForMap`，cosine UMAP；
- PCA64：公开范围 PCA64，欧氏 UMAP；
- 参数固定 `nNeighbors=24`、`minDist=.14`、`spread=1.25`、`nEpochs=350`；
- seed 固定为 `[1296126005, 1296126006, 1296126007]`；不挑最好 seed。

每个流程的第一个 seed作为参考窗口。其余布局只允许全局相似变换：平移、统一缩放、旋转；另报告允许镜像的 Procrustes 误差，但默认方向感不允许镜像。点 ID按稳定字典序对齐，不按坐标或标签匹配。

## 指标

1. 对齐前/后的点位位移：中位数、P95、最大值，除以参考窗口 RMS 尺度；记录旋转角、缩放和是否镜像更优。
2. 同流程跨 seed 的 k=15/30/60 邻域交集；与 R2 原高维邻域分开报告。稳定性不是语义正确性。
3. 跨流程参考窗口的邻域交集与对齐位移；若两个布局邻域不同但相似变换误差小，表示主要是坐标自由度；若对齐后误差仍大，表示结构差异或 UMAP 随机性。
4. 主题案例只作可读性反例：固定 R2 的 5 个代表，记录它们的对齐位移和跨 seed邻域变化；不按结果换案例。

不使用标签训练、不按视觉选择 seed、不生成新地形、不比较不同布局的密度高度。PCA64→UMAP 仍是流程研究，不是生产候选。

## 产物与验证

报告和低维坐标写入 `.private/research/map/alignment-stability/`。只读观察器后续可追加参考/对齐窗口，但本轮先完成数值和原文/案例审阅。没有远程请求、取数、模型推理或公开构建变更。

## 实况

### 1. 输入与运行

公开 snapshot/cache 与 R2 hash一致；实现hash记录在报告。两条流程×3 seed共6次UMAP，最新完整运行81.803秒，maxRSS 1,677,952 KiB（约1.60GiB）；Node v24.13.1、UMAP1.4.0。初次脚本运行后发现runtime计时只覆盖报告序列化，修正为覆盖完整UMAP/指标流程并重跑；数值字段没有因此变化。固定函数单测4/4、typecheck/lint通过。

### 2. 同流程换 seed：不能只视作旋转

以每条流程seed1296126005为参考，未允许镜像的相似变换误差 / 允许镜像的最佳误差如下。位移已除以参考窗口RMS尺度；k30是113个固定查询相对该流程参考窗口的邻域交集。

| 流程/seed | 直接对齐RMSE | 允许镜像RMSE | 对齐后位移中位/P95 | 成对距离相关 | k30邻域中位 |
| --- | ---: | ---: | ---: | ---: | ---: |
| RP96 / 1296126006 | 0.724 | 0.724 | 2.312 / 4.226 | .840 | 6.7% |
| RP96 / 1296126007 | 0.866 | 0.181 | 1.340 / 2.960 | .978 | 6.7% |
| PCA64 / 1296126006 | 0.864 | 0.136 | 1.418 / 2.741 | .990 | 16.7% |
| PCA64 / 1296126007 | 0.966 | 0.768 | 1.493 / 2.608 | .661 | 13.3% |

参考seed自身误差为0不是稳定性结果。允许镜像只作为诊断：RP96第三个seed和PCA64第二个seed的几何距离较高相关，但这不能证明访客方向可以随意反转；方向感产品默认不允许镜像。PCA64第二个seed的成对距离相关很高，却k30只有16.7%，说明全局距离相关和局部邻域保留不是同一指标。

### 3. 两条流程之间：结构和邻域均明显不同

固定seed1296126005，RP96与PCA64布局直接相似对齐后的RMSE `.825`，允许镜像最佳 `.666`，中位归一化位移 `.735`、P95 `1.331`，成对距离相关 `.796`，查询k30邻域交集的中位值 `6.7%`、均值 `11.7%`。这不是可以通过简单旋转/缩放合并的一对观察窗；PCA64→UMAP只能作为另一个窗口，不能覆盖或平滑变换线上地图。

### 4. 阶段判断

- UMAP seed会改变局部结构；相似变换只能处理一部分坐标自由度，不能自动提供连续、可逆的方向感。
- “成对距离相关高”不足以证明同一地图；必须同时报告局部邻域和对齐位移。
- RP96与PCA64的差异足以支持多视角研究，但当前证据不支持让访客在两个坐标系之间直接动画补间。线性补间仍不是高维观察平面的连续路径。
- 下一步R3-B固定一个参考布局，比较局部刚体对齐、共享锚点对齐和不对齐的案例可读性；必要时再研究带共同约束的布局，而不是直接引入AlignedUMAP。Mapper继续后置。

### R3-B：共享案例锚点

固定五个真实案例 `h-3501`、`h-898`、`h-2288`、`h-4504`、`h-1754` 作为坐标锚点，对 R3-A 六个布局分别做全局相似变换和案例锚点相似变换。相似变换保持精确的点间距离排序，因此两种变换的 k 邻域完全相同；它只可能改变屏幕位置与方向参照。

RP96 两个非参考 seed 的案例位移中位数为 `.875 → .871`，但固定查询位移为 `.675 → .814`；PCA64 为 `.728 → .645`，查询位移 `.813 → 1.035`。一类案例略有改善时，其他查询可能更差；没有通用赢家，也没有产品接入理由。
