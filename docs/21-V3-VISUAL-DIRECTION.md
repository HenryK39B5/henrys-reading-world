# 21 — V3 视觉方向：纸、墨、光与地形

> 日期：2026-09-18
>
> 状态：Batch 0 视觉权威。现有 V2 房间与 Book Aura 是可工作的基线，不是不可修改的最终外观；V3 允许系统性重构，但必须保护文字中心、真实内容、长文本、键盘、移动端与 reduced-motion。

## 1. 视觉命题

划线回顾产品的一屏一句、封面出处和分享卡片已是基础能力。Henry's Reading World 的审美不是装饰性抛光，而是产品提供情绪价值的主要方式之一。

新的视觉命题：

> **让真实文字像发生在一个安静但有纵深的世界中；房间由书的光照亮，小径由线索连接，地图让整个世界第一次可见。**

关键词：

- Editorial
- Spatial
- Quiet
- Tactile
- Topographic
- Luminous
- Restrained

## 2. 保留与重做

### 2.1 保留

- 真实中文文字是首要视觉中心；
- 宋体系舞台字与高可读 UI 字的基本分工；
- 大面积留白；
- Book Aura 来自真实封面，不给主题分配人为语义色；
- 分享卡片的出版物方向、双细框与出处 / 站点署名分层；
- 房间真实 URL、返回保留现场；
- 无裁剪、无 line-clamp、无假封面、无通用 AI 渐变；
- CSS 能完成的动效不引入动画库。

### 2.2 允许重做

- 全局排版比例、导航、房间标题与操作层级；
- 当前过于统一的列表、细线和 pill 控件；
- 门厅、书房、主题书架、小径的空间节奏；
- Book Aura 的形状与混合方式（仍保持低饱和与明确归属）；
- 分享卡片在加入全部标签后的完整构图；
- 页面在桌面和移动端的视觉构图；
- 地图专属的地形、点、标签与选中状态系统。

## 3. 核心材料：纸、墨、光

### 3.1 纸

基础不复制仿旧纸张纹理，不使用明显噪点。纸感来自：

- 温暖而非纯白的底色；
- 稳定、细腻的字色与规则线；
- 合理边距、字距、段间距；
- 少量层级差而不是卡片阴影堆叠。

地图可以使用同一纸面，也允许评估一套深色“夜间地图”，但第一原型优先验证与房间一致的浅纸地形，避免地图像外部插件。

### 3.2 墨

正文保持高对比墨色，不直接染成 Book Aura。墨色层级建议只保留少量：

- 正文；
- 出处 / 次要说明；
- 规则线 / 地形线；
- 禁用与背景信息。

标签不使用每个主题一个颜色，也不以不同字号表达热度。

### 3.3 光

Book Aura 是书籍进入世界的光：

- 门厅与主题 / 小径房间：当前书的低浓度环境色；
- 书籍房间：最明确；
- 世界地图：默认中性，点亮一本书时该书点使用 Aura；
- 分享卡片：允许更深、更完整的出版色域；
- 无封面统一回退 `DEFAULT_ACCENT`。

第一眼必须读到文字，第二眼感到环境温度，第三眼才意识到颜色来自书。

## 4. 字体与排版

### 4.1 文字舞台

- 继续根据真实短 / 中 / 长内容调整字号和行距；
- 不追求每条都占满首屏；
- 短句允许更强的版面存在感，长文允许页面自然增长；
- 保留原始标点与换行；
- 最大行宽以中文连续阅读舒适度为准，不为地图或标签压窄正文；
- 标签、出处和操作必须明显低于正文权重。

### 4.2 UI 文案

UI 字体负责导航、计数、按钮和工具信息；不使用大段全大写英文制造“高级感”。中文命名优先清楚，再保留轻微文学感：

```text
线索  #希望  #机会
正在沿着：希望
这一程已遇见 6 / 37 处
在世界地图中看看这本书
```

### 4.3 层级

每个房间只允许一个视觉中心。避免同时出现：大标题、大句子、大封面、大统计、大 CTA。

- 门厅中心：划线；
- 书房中心：当前划线，封面是环境锚点；
- 小径中心：当前划线与当前线索；
- 地图中心：世界地形；
- Studio 中心：任务和审核状态，不追求消费者页面的沉浸感。

## 5. 导航与控制

主导航保持文字化、低权重、可发现。V3 可重新评估当前横排间距与移动端换行，但不做固定底部 App Tab、汉堡菜单迷宫或图标优先导航。

按钮分三层：

1. 当前主动作：`再来一句 / 继续沿着…… / 再看一处`；
2. 空间出口：`查看这本书 / 转向…… / 打开地图`；
3. 工具动作：`分享 / 复制 / 关闭`。

不让所有操作都成为 pill。圆角胶囊只用于确实需要包围的紧凑控制；线索更适合文字链接、细下划线或轻量标记。

所有触控目标继续至少 44px，但视觉边界可以小于命中区域。

## 6. 线索与小径视觉

### 6.1 划线下方

推荐层级：

```text
<划线正文>

——《书名》作者 · 时间

线索  #希望  #机会

[继续沿着「希望」走] [分享]
```

- `线索` 是说明；
- `#希望` 是可进入链接；
- 当前小径标签需要明确 active，但不做高饱和彩块；
- 1–3 个标签全部显示并可换行；
- 标签出现不能把正文挤出首个有效视口。

### 6.2 岔路

点击另一个线索时，当前文字保持。视觉需要让用户感知“方向改变、地点未变”：

- 当前路径标题 / breadcrumb 更新；
- 新路径线索获得 active 状态；
- 当前卡片不闪退、不重新入场；
- 下一次“继续沿着……”才触发文字过渡；
- reduced-motion 下同样准确但不位移。

不画夸张的分叉道路动画；语义由标签状态、微弱方向提示和保持当前句共同完成。

### 6.3 小径列表

本质是标签列表，但呈现为可进入路径：

- 名称；
- 一句定义；
- `N 本书 · M 处划线`；
- 轻微分隔与稳定阅读节奏；
- 可与地图互切。

不做标签云、词频墙、彩色卡片网格或排行榜。

## 7. 世界地图视觉

### 7.1 目标

地图首先应作为一张视觉作品成立，然后才是交互层。它需要让人感到：这些划线确实共同形成了一个世界，而不是看到一张技术散点图。

### 7.2 图层

建议从后向前：

1. 纸面 / 夜色基础；
2. 极轻网格或坐标气息（可选，不能像工程图）；
3. 密度场与等高线；
4. 全部划线点；
5. 标签山峰名称；
6. 当前主题 / 当前书 / 当前划线状态；
7. 地图上的划线详情层。

### 7.3 点

- 总览点很小，主要表达密度；
- 不按 Topic Tag 分配彩虹色；
- 默认点使用低对比墨色 / 微光；
- 当前主题点提高对比；
- 当前书点使用 Book Aura；
- 当前 highlight 是清晰焦点；
- 多标签点可以使用双环、空心点或细微 halo，不能抢过山峰名称。

### 7.4 山峰与等高线

- 等高线来自真实密度，不手画成装饰山；
- 相近主题可以共享山脉；
- 标签名称需要避让，不能压住密集点；
- 字号不按“热门程度”大幅变化；
- 地图标签与路径名称完全一致；
- 若一个标签分布异常分散，先回到内容审核，而不是强行画成一个峰。

### 7.5 交互反馈

总览：

- hover / focus 标签时显示定义、书数、划线数；
- 点击进入区域；
- 地图位置与缩放可返回恢复。

主题区域：

- 当前区域变清晰；
- 相邻主题保留方向感；
- 点可点击 / 键盘等价列表可操作；
- 地图上的划线详情关闭后回到原位置。

点亮一本书：

- 该书点以 Aura 亮起；
- 其他点渐弱但不消失；
- 不画连接所有点的边；
- 显示书名、点数、涉及小径；
- 可以从一个亮点打开该书的一处划线。

## 8. 地图的响应式与性能外观

### 桌面

- 地图可以占据接近完整视口；
- 说明和控制保持边缘低权重；
- 不用传统数据仪表盘侧栏围住地图。

### 移动端

- `/paths` 默认列表；
- 用户主动打开地图后进入专注全屏画布；
- 大标签可点击，单点只在区域层交互；
- 地图控制数量最小化；
- 随时可回列表。

### 无障碍

地图不是唯一导航：

- 提供同数据的小径列表；
- 区域层提供当前点的语义列表；
- 当前状态有文本说明；
- 颜色不作为唯一状态编码；
- 200% 缩放时仍能到达主要控制。

## 9. 分享卡片 V3

保留现有 Book Aura 深色出版卡片方向，加入全部标签：

```text
<正文>

#希望 #机会 #不确定性

────────
《书名》
作者

────────
Henry's Reading World
```

要求：

- 全部标签，不 `+N`；
- 标签自然换行，卡片必要时增高；
- 正文仍然最大；
- 标签与出处之间有清晰层级；
- 不加头像、阅读统计、日期、二维码、模板选择或封面背景；
- 分享视觉需在短句、中句、299 / 398 字、多标签和 390px 下实测；
- CSS 预览先行，图片导出仍需另行决定。

## 10. 动效语言

### 10.1 房间

现有 8–12px / 320–420ms 的房间进入可以作为基线，但 V3 允许基于真实截图和浏览器体验调整。动效用于说明空间变化，不用于持续吸引注意。

### 10.2 文字

- 换句仍是原位淡出 / 淡入；
- 快速点击只提交最终有效状态；
- Book Aura 变化慢于文字；
- 小径切换但当前句不变时，不播放换句动画。

### 10.3 地图

- 世界 → 区域允许温和缩放 / 平移；
- 点亮一本书允许短暂渐显；
- 不做永久漂浮、粒子、路径流光或 3D 地球；
- reduced-motion 直接切换视图与选中状态，保持地图位置和焦点。

## 11. 禁止方向

- 通用 SaaS / AI 落地页视觉；
- 大面积高饱和渐变、玻璃拟态、霓虹和随机光斑；
- 数据指标卡阵列；
- 标签云、热度字号、彩虹分类；
- 书封拼贴墙；
- 仿旧纸张、复古墨迹和装饰性巨大引号；
- 地图节点蜘蛛网；
- 为了海报感牺牲交互、长文本与移动端；
- 为了交互把地图做成 GIS / BI 工具；
- 复制用户提供的产品截图或 flomo 地图皮肤。

用户提供的参考图片只用于分析产品规律，不作为项目素材，不复制到仓库或公开产物。

## 12. 视觉施工顺序

1. **视觉审计**：当前房间、分享卡片、真实长短文与移动端；
2. **静态方向稿**：门厅、小径房间、世界地图三张关键画面；
3. **设计 tokens**：纸、墨、规则线、Aura、字号、空间与状态；
4. **小径 MVP**：在真实标签试点上实现线索、岔路和路径节奏；
5. **全局房间统一**：门厅、书架、书房、About；
6. **地图**：先世界总览，再区域与点亮一本书；
7. **分享卡片 V3**：全部标签与长文；
8. **真实浏览器 Gate**：桌面 / 移动 / 200% / 键盘 / reduced-motion / 长文本。

## 13. 视觉 Gate

每个主要阶段至少提供：

- 1440 桌面；
- 390 移动；
- 320 或 360 窄屏；
- 短、中、最长划线；
- 1 / 2 / 3 标签；
- 岔路切换前后；
- Book Aura 至少 6 本差异样本；
- 地图默认 / 主题区域 / 点亮一本书；
- 200% 缩放；
- reduced-motion；
- 完整键盘主路径；
- 对比度、溢出、最小命中区域、裁剪和 DOM 数量实测。

真机移动端与 Safari 不可用时继续诚实标为未验证，不能用 Chromium 模拟冒充。
