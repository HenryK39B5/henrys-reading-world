# R4-J — 同一真实路线的三种阅读入口（本机试用）

日期：2026-09-27。**试用前约定**；Henry自愿作为知情项目使用者，不是独立首次访客、盲审或多人样本。R4-I的数值/语义诊断已结束；本轮只比较相同内容在阅读与地图之间的呈现先后。未得到 Henry 实际反馈前不能写“某视图获胜”。

## 固定条件与任务

- 冻结 `.private/research/map/route-first/viewer-data.json`（3,462 条已审核公开真划线、原图有向前16近邻、已发布二维坐标/轮廓、11个入口），不变更候选、排名、段位或种子。一个页面、一个trail、一组候选：切换视图不重置起点/路线、不生成不同的选择。
- 三个原生单选按钮：**纯文字岔路**（无地图、划线与岔路优先）、**阅读＋地图**（划线后可看地图，再到岔路）、**地图优先**（地图作为路线方位入口，随后仍能看完整划线与岔路）。地图固定表示发布坐标，实线是已走顺序、虚线是可选跳转；模式变化不改含义、不得用颜色独自表达差别。不做第三套新布局/算法/路线推荐，不接入消费者/公开包。
- 给 Henry 的简短、非计分任务：从预设真实起点读一句，按自己兴趣走两步；保持同一站切换三种呈现，再回到前一站改选。如果没有合格分支，就诚实停下。任选桌面或手机，若方便可各看一次；死路 `h-043` 和后验长跳 `h-898` 可自行选看，但不是成功条件。结束后只需用自己的话说：哪种入口愿意继续、点线各像什么、哪里读/找/返回费力；不要求逐题标注或编造首次访客记录。

## 预先定义的失败与检查

- **工程失败**：任一视图切换使真实ID/书名/全文/同段候选或trail改变；键盘无法切换或返回；文字视图仍泄露可见Canvas；地图视图消失后画布不重绘；320/390/720/1440横向溢出、断句或不尊重reduced-motion；白名单服务器读出未允许数据或产生外部请求。做浏览器真实交互/像素、纯函数/构建隔离与截图；本轮无新算法数值胜率。
- **体验受阻（Henry反馈待填）**：误认为线是地形道路、每一跳都验证了语义相同；需要下滚过多才找到可选岔路；切换模式看不出入口差异或找不到原文/返回；为了地图牺牲继续阅读意愿。三种模式若各有长短，如实记录，不选赢家。测试屏幕高度与手机首屏实际内容，不把720px视口称为真200%缩放。
- 截图、哈希、原始测量、命令/失败存`.private/research/map/route-first/three-view/`；浏览器数据只读，自带单次试用服务只监听127.0.0.1，告知Henry停止方式。完成工程验证只算**待 Henry 试用**；真机Safari/iOS、读屏、实际200%缩放、低端性能、权利和发布仍分开。无 `src/`、`public/`、部署或push。

## Henry知情试用反馈（2026-09-27）

Henry在本轮会话主动表达体验，原话保存在`.private/research/map/route-first/three-view/henry-feedback-2026-09-27.md`。没有记录其实际每一步ID、用时或是否按任务卡试完三视图/手机，**不能**从这份自述计算完成率、语义准确率、首次访客成功率或宣布某个三视图获胜。以下为忠于原话的研究归纳，并非独立评审：

- 第一眼认可本机研究页的视觉；喜欢文字岔路用有向模型邻居进行漫步，尤其惊喜于在已发布地图坐标参照上看自己走过的轨迹。他认为这一交互思路也可能适合主题路径，**尚不是授权改公开路径页**。
- 选择岔路带来参与感，也让访客不得不预览几段文字、纠结选择并惦记未选路径；Henry主动提出可由漫步算法直接走到下一句，以减少决策负担，同时联想到此前“随便一句”。两者不可直接等同：本轮自动下一句若研究，应仍以冻结真实起点、同一前16有向跨书邻居和明确的选择规则为条件，而不是冒充全局任意抽取。**没有定下纯自动取代所有岔路**；选择本身的乐趣和人生隐喻亦是原反馈的一部分。
- 两种图文并用的顺序排布让地图/句子上下分离、来回滚动；需要能方便对照的图文关系，而非单纯交换前后顺序。旧工程测量的手机岔路下移是一个与之相符的界面事实，但不能替Henry量化不满程度。先决定关系，再做细节打磨。
- Henry既希望探索更特别且有意义的语义空间可视化，也认为现已上线世界地图的点位、距离、标签在他手动逐点漫游时有实际阅读联系。尊重这份体验，不因先前模型邻居保留诊断就断言发布地图“没有意义”；也不把个人体验升级为逐对语义真值。现有线上地图继续作为可用参照，R4-J无替换或发布Gate。

试用入口在反馈后已停止：先核对`127.0.0.1:5201`持有进程的命令行为`serve-route-viewer.ts --port=5201`，再仅终止匹配的PID 16844，并确认本机端口不再监听；没有关闭其他服务。

**后续仅作为隔离研究提议**：对同一句/同图位/同一已冻结邻居，观察“默认一步一读、必要时轻量展开分叉”与“三选一岔路”是否在继续阅读意愿和控制感上各有所长；同时做地图和正文能对照的局部布局，而不向手机简单堆全幅图。研究仍需先写失败标准、保留长跳/漂移/死路与键盘/无障碍退路。是否将其变为正式主题路径/世界地图的核心模式，待后续明确产品决定。
