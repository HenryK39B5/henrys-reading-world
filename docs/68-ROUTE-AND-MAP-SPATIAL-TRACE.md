# R4-I — 原空间阅读路线 × 已发布二维地图的空间轨迹

日期：2026-09-27。预登记后完成数值与本机浏览器试验，未选生产方案。R4-G/H 的局部跨书路线能在浏览器走，但目前只是卡片岔路；用相同真实点的**已发布二维坐标**画一条行程轨迹，检查是否能增加世界方位感，或者只产生误导性远距连线。现有线上点位/地形仅作**只读参照**，不得改变。

## 固定数值对照

- 使用已核对的公开3,462划线、`snapshot.map.points`完整坐标、R4-G 冻结的108书起点+5例两组完整路线及前16有向原空间cosine邻居；同时校验公开快照/缓存/研究报告 hash。每一步只在真实源/终点上计算二维距离：`sqrt(dx²+dy²)/(10000×sqrt(2))`，并计算终点按二维欧氏距离在其源句的**全部3461条**其他点中的名次（同距离按ID排序），统计命中二维top30、距离中位和P90。它们是坐标诊断，不是语义正确率。
- 匹配书籍对照：对每条真实边固定当前源点、目标书，用按路线种子/方式/步序的固定PRNG从**目标同一本书**随机抽一条划线，重复书内只有1条时如实记自同一端点；报告这条基线的二维距离中位/P90和原边相对基线更近/更远的次数。不把同书随机基线当负样本、统计显著性或优化目标。必须分别给预先固定的108书起点与5例、两类路线结果；保留每边原始和对照坐标/排名到`.private`以便复验。
- 原文检查仍用已有5例真实路线，不按地图上看着好看的路径后验选案例。注意R4-G起点按书ID首条并非随机访客样本、重复路线/同书目标让边相关；R2已显示二维近邻保留低，任何“长跳”只是不同表示间的不一致，不能证明该步没意思。预先不设需要多少条“短边”才能上线。

## 可见地图轨迹与门槛

本机viewer-data仅新增**已审核公开**的地图坐标/轮廓，不含向量；约3.71MB，二次生成逐字节SHA256 `f95cfa8bb830a9e2600fceeb69a7101910c85906f452d207dde04431f99fca6d`。Canvas在固定地图点/轮廓上淡绘3462点，并将当前已访问最多7点画为实线，当前可选最多3条候选画为虚线；文案明示“实线是阅读顺序/虚线是可选跳转，不是地形道路”。保留原始全文、书籍、键盘可访问的文本路线；地图本身只是可选视觉参照。点击任意实际分支后，局部文字列出原空间top16排名、发布二维名次和占图对角线百分比，**没有**把R4-G PRNG预定路线冒充交互选择。
