## 7D-1：最小可交互全深跨页样板

- 范围仅为地图房间（世界、区域、点亮书、真实详情、语义列表）及其所在页面外壳；暂不一键反转所有房间或分享卡。导航到其他房间时继续使用原有浅色7A样式，避免把样板当作全站完成。
- 地图的深墨绿与阅读的暖深灰属于同一连续色域；使用局部层次、文字版心与来源标记表示跨页，不用移动端白纸硬切、星空或假海岸。地图坐标 / 密度值 / 等高线段仍由原始布局提供；Canvas 绘制颜色可以调整，位置不动。Book Aura 仍只来自书封或已有 fallback，不给标签分配语义色。
- 手机点开详情时正文先到眼前，不再让访客越过一整块地图去找引文；全文、全部标签、出处、书房/小径/分享出口可用；桌面构图与手机有各自适配，不以宽屏缩放替代。
