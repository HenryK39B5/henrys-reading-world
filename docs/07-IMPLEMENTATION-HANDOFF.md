## 如何使用两个模型

**DeepSeek 负责：** 按契约写组件、CSS、纯函数、测试、只读取数辅助和已获授权数据整理，修确定的 bug。

**回到高推理模型的时点：**

1. 文档间存在真正产品冲突，或拟改变原型范围。
2. 核心视觉虽“正确”但没有继续探索欲，需要体验批评。
3. Slice 4 可走通，有真实页面证据，进行 Critique #1。
4. 真实访客反馈后决定是否进入正式数据与发布架构。

普通排版微调、局部组件拆分和测试修复无需升级；私密内容取数 / 公开授权由用户决定，模型能力高低都不能代签。
