# R4-K — 单步续读 × 自选岔路：图文共视本机小样

日期：2026-09-27。Henry在R4-J知情单人试用后明确授权继续隔离研究：认同真实文字岔路/地图轨迹，但担心每步三选的预读与决策负担、图文上下隔离；同时肯定已发布世界地图的逐点漫游意义。原话与边界见`docs/69`。**本文件先登记失败条件与续读规则，再实现；不表示用户已选单步续读、主题路径改版或新地图产品方向。**

## 不变条件、两种走法

- 唯一输入是R4-H/I/J已经冻结的本机只读`viewer-data.json`：3,462条已审核公开真实划线、前16有向原空间cosine邻居、同一已发布2D点与轮廓，当前SHA256 `f95cfa8bb830a9e2600fceeb69a7101910c85906f452d207dde04431f99fca6d`。不重新算embedding、不调点位/地名、也不从未审核内容构造示例。原R4-J观察器和线上`src/`、`public/`原样保留。
- **默认单步续读**：访客读完整当前真句后，可主动按一次“再读一句”，无需提前看三个候选；不是计时自动翻页。当前有向前16内先排除已走ID和同书划线；按步序期待段位`近端1–4 → 侧边5–10 → 外缘11–16 → 侧边 → 近端 → 外缘`，期待段空时显式回退到全部合格前16；再在选中段/回退池内优先此前未访问的书；在最终合格集合中用固定seed、对**当前完整路线ID**可重算的PRNG抽一条。记录该条实际模型rank/段回退/书籍/发布2D距离；不是`R4-G`预定路线的逐步重放，更不是全局随机的“随便一句”。保留同一历史回退、至多6跳与真死路，回退后重走同一历史选到同一点；改走别路以后种子随历史变化。
- **可选主动岔路**：选择“自己选路”才出现至多三张小卡，分别对应近端/侧边/外缘，遵循相同去重、跨书和新书优先约束；如该段有默认续读目标，卡片也必须包含目标，避免两种模式的下一句悄悄不可比较。点选后加入同一trail；切换走法不清空历史。两种走法的选择依据只在原空间，**地图距离不用于推荐/惩罚**；虚线只在主动岔路打开时提示可能跳转，实线只表示已走的阅读顺序。

## 共视实验与判败

- 同一个本机loopback只读观察器的新白名单入口，桌面让地图/完整真句并排，手机将**小型地图紧邻当前句**，不用将整张方形地图插在全文与下一步之间；不能伪装地图线为道路。文本路线和书籍/ID为Canvas的非图像退路；地图点数在Canvas而非3462 DOM。地图使用同一世界坐标的等比例正方形，不通过拉伸美化短边。
- **硬失败**：自动下一句不在真实前16中、同书/重复ID、不满足公开快照ID；历史相同返回时目标变动；两模式切换清空trail/更换句子；默认目标不在展开岔路中且同段可表示；短/长/换行被截断；真死路时仍生成下一句；CPU/GPU/无障碍缺陷导致键盘、320/390/720/1440、reduced-motion、无横向滚动或数据白名单失败。纯函数用可注入RNG测试端点/回退/书籍公平/确定性，浏览器核对真实rank/地图坐标/截图与自选分支回溯。
- **软失败或待用户判断**：所谓共视在390或320首屏仍要大幅来回滚动，地图小到无法辨别点或盖住长文本；自动行走掉进书内词面/段落组织漂移、把远距线说成“已验证同主题”；不点击选项使自主权与再次遇到的意外感一同消失。保留5个固定原文案例、已知`h-043`零步死路和后验`h-898`长跳诊断，不能只挑好看的路线。人工体验由Henry自愿提供，不设批量标注任务，不凭Agent或浏览器测试称访客成功。
- 截图/日志/私有逐步痕迹留`.private/research/map/route-first/next-step/`；脚本、测试、文档可Git小步提交，浏览器真缩放/Safari/iOS/读屏/低端性能与引文封面权利仍独立开放。没有用户产品Gate不得整合正式世界/主题路径、push或部署。
