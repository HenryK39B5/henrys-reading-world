# R4-H — 本机岔路观察器：读起来是否有意思

日期：2026-09-27。R4-G 数值基线显示局部有向前16近邻路线多数可完成跨书6跳，也有书籍元词漂移；数值只能决定**值得观察**，不能证明体验有趣。先锁定本机观察器及失败检查再实现。

- 仅从已核对的公开3462条划线和本机R4-E向量近邻图导出 `.private/research/map/route-first/viewer-data.json`：ID、公开书名/书ID、真实全文、前三个原空间排名分段的16个邻居ID/score；不导出1024维向量、私有标注理由或用户R4-D回答。严格匹配快照、缓存和图hash；无新远程调用。
- 独立 `127.0.0.1:5201` 单机**只读**网页，不接 Vite 正式应用/生产。白名单 `/`、`/viewer.css`、`/viewer.mjs`、`/viewer-data.json`；拒绝其他路径/方法/外来 Origin，CSP 同源、no-store。启动按已有材料加载；关闭测试服务，不自动长期运行或发布。
- 交互：10个固定起点（R4-G 5病例+按书ID前5个书种子；去重），另加数值结果中已知在0跳终止的 h-043 作为**结果已知的后补失败测试入口**，不纳入事先固定样本/成功率，展示当前真实划线全文和书名；每步最多给“近端（排名1–4）/侧边（5–10）/外缘（11–16）”各一个**实际跨书未见**选项，优先未到过书、同段中按排名最高作确定性预览，而非三种确定的语义关系。按钮打开对应真实全文、原路与返回、从头开始；至多6跳；当前若无合格跨书边，显示“走到这里”，不捏造桥。路线图只画访问顺序/书籍，不把二维距离写作相似度。debug 明示真实 rank/score 和回退/无候选，只给研究者看。
- 验收：已核对真实原文、书/ID与图同源；浏览器1440/390/320及720（200%等效）截图，键盘Tab/Enter/返回、完整长文本、reduced motion、无横向溢出、失败入口/非法路由，网络无外部请求；测试中捕获选择回退与原创句ID对应。视觉反馈应保留“可能漂移”，不能只截最美案例。此门槛不是正式访客测试或产品上线Gate。
- 若实际 UI 仍使读者误会三选项必为同一主题、局部书籍偏置不舒服或手机长文无法承受，修正或停止；只有本机可走、可读并保留不确定性才提出后续产品讨论。无需用户做额外标注；不改正式 `src/`、`public/`、坐标、地形或部署。

## 实况（2026-09-27）

本机导出器复跑两次、viewer-data.json SHA256 一致（`a325232c6a1f8bc87c37f91e1ccc690a003fb414accbada8b43156dd33e7ba4d`）；3,462条原文/书籍和前16有向排名，11个入口中第11个 h-043 是**事后补充的0跳死路负例**，不纳入R4-G预定种子统计。数据文件约3.55MB，未带原1024维向量/用户填写。只读loopback/白名单服务 `node scripts/research/serve-route-viewer.ts --port=5201`，先运行 `node scripts/research/build-route-viewer-data.ts`；Playwright会自行启动及关闭临时服务，本轮没有常驻监听端口。

当前页只呈现真实原文、原始书名、访问顺序与每个段的**至多一个**跨书未见候选；没有就明确空，6跳后允许沿途返回但不再自动造第7步。rank/score仅为研究证据；从h-3501开始近端候选为空，侧边/外缘分支可见，不隐藏失败；h-043全部3段为空。点击下一句后焦点返回新原文标题并滚动入视口（第一次浏览器观察发现程序焦点虽到标题但滚动仍停在旧选项，已修复）；键盘Enter、上一步、重走、换起点、6跳回溯均有浏览器覆盖。

Chromium 真实浏览器6/6：1440/720/390/320宽、reduced-motion，截图在`.private/research/map/route-first/screenshots/`（`crossroads`/`step1`/`education`/`dead-end`四宽 + `deep-route-390.png`）。720仅是视口代理，**非真正200%浏览器缩放**；浏览器核对每一步ID仍是当前有向原图候选且跨书、真实全文未丢、页面无横向溢出/外部请求。`/.private/...`、答案键路径404，POST405、外来Origin/Host403；节点代码不使用HTML注入显示原文。全套51文件369项、typecheck/lint/build/公开隔离/publication parity通过，公开产物资源指纹未变；WebKit/Safari/真机/读屏/低端设备和独立访客尚未测。

**视觉/体验判断（研究者非独立）**：当前成品是安静、可读的*书摘岔路卡*，不是有明显空间方位感的“阅读世界地图”。390/320手机的真实长文及三个选择需明显下滚；可重复跳进同类财经/官场语境，h-4504早期岔路会引向宽泛的书籍/精英词面，而h-2288有可跟随的“意义→认知偏误”支线。它证明浏览器能真实选择、回溯和遇死路，**不能**证明人会觉得有意思、节奏胜过现有小径，或原向量图就是新产品地图。下一步若继续，研究“地图的方位”与“阅读的路径”如何并置，或观察真实首次访客，而不是把此页直接移进公开站点。
