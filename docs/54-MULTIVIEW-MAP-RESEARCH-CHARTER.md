## 1. 从用户问题到研究方向

本记录是对会话的整理，不是逐字引语；不把 Agent 提案写成用户已经确认的算法。

1. Henry 在手机上认可现有地图效果，但注意到大片地形没有主题名称，希望地图更容易理解。
2. 随后决定暂时接受无名区域，不以填满地图为目标；重点转为主题名称的空间代表性：名称附近的真实句子应该能够支持这个主题。
3. 当前名称不是平均坐标，而是成员点 X/Y 分别取中位数。主题存在、小径存在、地图上有可信锚点、某视口绘出文字，是四件不同的事。
4. Henry 提出主题 embedding 是否能给出更合理的位置。Agent 提议比较二维中位数、真实成员 medoid、局部支撑锚点及聚合向量的投影，而不是直接采纳某一个。
5. Henry 进一步提出：二维窗口可以固定，但生成窗口的投影可以随关注主题变化；不必始终把所有语义关系压在同一张平面上。
6. Henry 明确授权投入持续研究：可在隔离实验中更换地图算法、embedding 模型与生产流程，没有 DDL；当前生产实现不是不可突破的限制。未来博客应保留失败、纠正和真实证据，而不是只复述最终方案。
7. Henry 认可研究拓扑摘要、主题透镜及空间代表性；具体模型、算法、阈值、界面和上线候选尚未确定。

## 2. 本轮达成的产品原则

- 地图地名是一种局部空间声明，不只是主题目录上的一个词。
- 未标注划线表示缺少已复核标签，不能当作某主题的确认负例。
- 二维邻近、密度、语义相似、标签身份、书籍多样性和个人认同，不可互相替代。
- 不保证每片地形有名字，不为了视觉覆盖率补标签。
- 多维 embedding 是模型表示，不是完整真实语义；投影指标不能替代原文审阅。
- “显影透镜”只改变编码；“投影透镜”改变坐标。2.x 维只是产品讨论比喻，不是数学维数。
- 地图、Mapper 图、主题小径各自的节点/边/距离必须有可解释定义。
- 不声称首创或研究发现，除非检索、对照、复现实验与证据真正支持。

## 4.1 研究门槛调整（Henry，2026-09-27）

Henry 认为 R4-D 的“两个答案相近”混淆了 A/B 彼此相似和 A/B 分别与锚点相似；快速作答的理解误差和人工标注成本不值得把 36 题当作进展门槛。截至本次讨论，对话 001–003 与本机填写 004–011 共 11 题有回答；未答题不是负例，也不要求 Henry 补完。原文/答案及未答状态保留，旧预登记和失败不回写。Agent 可对少数特殊原文独立作研究者判断，注明身份、依据、分歧和不确定性；不伪装成独立盲审或模型准确率。

新的工作目标是让 **embedding 表示中的邻近关系、二维导航和主题探索之间的建模更合理**，不追求唯一/最优语义真值或全量人工标签。下一步优先把归一化高维向量上的相似关系与二维地图导航分层：相似度在模型空间按明示度量计算，二维投影服务方向感和概览，不能因为二维像素近就断言语义近；主题名/边需分别说明其来源和适用范围。原空间相似也只是模型诊断，不是人的理解。比较少数可重跑的简化方案（例如受控近邻连接与现有地图/Mapper），不以强制聚类的节点数、覆盖率或分数拟合自身来选赢家。排查明显词面错配、单书偏置、断裂/巨型结构、种子与尺度敏感性和真实页面的可读性；资源、稳定性、无障碍及体验同样进入判断。失败如实保留，可以选择一个有局限但有依据的本机候选继续做观察器，而无需先完成独立语义盲审。

这放宽的是**研究推进的验收方式**，不是对外说法或发布授权：不得把模型邻近、读者少量反馈、研究者判断写成语义真值；研究不自动更改已发布地图、公开快照、地名、地形、运行时 API 或部署。若将来提出生产候选，仍需独立的产品/视觉/无障碍/发布决策。

## 4.2 拓扑灵感与体验优先的补充（Henry，2026-09-27）

Henry 允许更广泛地借鉴拓扑等学科，并明确提出产品中“有意思但不准确”可能优于“准确但没意思”。这是允许隔离实验为了阅读的发现感探索意料之外的连接，**不是**允许编造划线、把弱模型邻近说成确定相同观点、或在发布站点悄悄换地形。产品取舍需分别描述趣味/可探索性与关系依据/误导风险；“跨书对照”和“同一主题”尤其不可混叫。

R4-E 的固定强边阈值出现单点海/巨型块；R4-F 的真实地标—见证压缩有明确见证边，但max-min选择离群片段、同书偏置和64→128边失稳。见`docs/64`、`docs/65`。拓扑术语用得严格：前者只扫描图连通分量，不是完整持久同调；后者只实现地标最近两名见证的一阶边，不是完整见证复形。可继续研究多尺度地图/路标与读者自主漫游，也可在有足够原文和视觉证据时建立*隔离的本机*有趣路线观察器；两个已失败的统一骨架不能凭单个趣味案例变成“新语义地图”。

## 4.3 路线与地图的关系（R4-I，2026-09-27）

已发布二维坐标是**地图位置**，前16模型邻居是**候选的生成依据**，读者点击后的实线是**走过的先后顺序**。三者必须分别定义；短线也不是“观点相同”，长线也不是“没有意思”。固定108本各638条跨书边的两类路线只有105/128条落在二维top30，虽比同目标书随机句的地图距离中位短，仍有远距突变；分组/控制与后验长跳截图见`docs/68`。本机Canvas观察器让位移可见，也把手机全文下滚推得更远，研究者不把它判断为可上线产品或独立访客喜好。今后若设计地图层/阅读层切换，应保留同句ID、方法/路线来源、清晰返回和误导性连线的原文反例；不得用二维短边数、模型rank或单张优美截图挑选产品赢家。生产集成仍要独立视觉/体验、无障碍与公开发布Gate。

## 4.4 知情使用者观察而非假访客（R4-J，2026-09-27）

Henry主动提出自己作为本次使用者。采用同一个本机路线观察器，在同一句/同组候选中切换纯文字、先读后看图、先看图再读三种入口；不是新算法A/B，变化只有呈现顺序，学习效应、预知产品背景、单人样本及已读文本都不能消除。访谈要让Henry自己说愿不愿继续、对点/线的理解和找岔路/返回成本；任何主观偏好都须记为**知情单人反馈**，不能当独立首次访客成功率、语义正确率或发布授权。工程完成不自动选出赢家；Henry后续反馈认可文字岔路与地图轨迹的组合，同时指出多选决策成本与图文上下割裂，也肯定发布地图的逐点阅读意义。原话本机留存、任务卡与忠实归纳见`docs/69`；不推定其完成全部试用任务。下一轮可在隔离研究中区分**自动续读的低负担**与**可选岔路的自主权**，保持同一真实句子/图位/候选依据及回退，而不恢复“随便一句”的随机抽句语义或直接更改公开主题路径/世界地图。

## 4.5 单步漫步不等于可读语义保证（R4-K，2026-09-27）

同一前16真实有向邻居、同一已发布地图坐标上，R4-K允许读者主动按一次“再读一句”而无需先看三张预览，也随时能切换自选分支/返回。段位节奏、跨书、未读、新书优先和固定历史种子均有明示规则；2D距离不参与选择。11个既有入口中10个走满6步，并不等于更有趣、准确或更公平：原文出现h-3501进入交易题材窄走廊、h-2288抽象相似漂移、h-4504模型rank7却发布地图长跳49.4%对角线。小图和正文在桌面同列关系更近、手机上下相邻但长句/按钮仍会下滚；这一段是Henry反馈前的视口几何与Agent判断，不是首次访客验证。Henry后续作为知情单人用户认可地图/划线共视，同时指出并列模式的负担与地图未固定导致游走感不足；原话和下一轮隔离比较范围见`docs/70`。报告、长跳/死路与失败记录亦见`docs/70`。线上世界地图继续是独立可用的参照，不因这个局部交互而被替换；R4-J旧卡保留供对照，两个本机试验都不构成产品/发布Gate。

## 4.6 从地形图到星座/书岛图（R4-L，2026-09-27）

Henry认可更合理、更有趣而非唯一正确的目标，并授权试不同的“图”。R4-L在**同一真实11起点/60条R4-K已走边**上冻结阅读内容与规则，只切换画法和已声明的书籍索引坐标：已发布点云简图（非完整地形线上渲染）、同发布点位的局部模型邻居星座图、真实108本划线数排序的书岛图。三页前进/回退与当前点稳定、浏览器工程通过，不表示哪张图更好。星座边是真实前16内已过滤的少量近邻但不是已确认主题；书岛位置来自数量/ID，不是书籍/主题间真实语义距离。研究者看截图时星座线帮助分清少量连接；108岛在窄屏仅数像素且像索引网格，不能把“跨岛”包装成新的准确地理。数值所见书岛跨岛距离大只是索引造成，**不与发布二维距离比较准确率**。截图/数字/原文反例与首跑固定地图跳动修正见`docs/71`，Henry随后体验并认为书岛图怪异且缺美感/有效信息，星座线没有提供有用的关联理解；这是知情单人审美/价值反馈，不是独立访客统计，工程通过不能凌驾此判断。两个新增图暂停作为产品候选，完整原话及归纳见`docs/71`，正式地图/路径/发布Gate未开启。下次先说明一张图在原文之外让人读懂的具体真实信息，再决定是否需要另一种图形编码；标签交集、书籍身份、模型rank与读者眼中可读的转折必须分别标明、保留缺失/反例，美感不可作为给弱关系涂色的借口。进一步尝试新几何时应单独预登记布局及稳定性研究，不能把纯视觉风格的小样叫新语义算法。

## 4.7 阅读故事的信息契约（R4-M，2026-09-27）

Henry指出增加线/书岛形式若未使读者理解有价值的信息，画面漂亮也无效；R4-M先明确三个真实问题，再统一到一个不需切模式的入口：**世界里还有哪些同标签的已审核真实划线与书籍**（当前真实标签的部分透镜，不把未知/未标点当负例）；**这段跨书路线为何看似在走却可能回旋**（已走书/标签交集织锦，不窥未选下一站）；**相邻原文各说了什么**（可按需打开双全文与标签/模型排名、读者自己判断视角）。60条固定边26条有共享标签、10条双方已标但不共享、24条至少一端缺标，既不是语义正确率也不是“缺标=没主题”。R4-K路线中的金融走廊/抽象漂移/长二维跳均未删掉；工程/截图/初查手机图例修正见`docs/72`。此图仍在相同旧坐标上、没有用户审美与信息价值Gate，不能称实现世界图创新胜出。标签是审核分类证据，不是相似真值；动态光斑和织线只是依据的载体，不能靠颜色/熟悉的图形伪装未证语义。

## 4.8 直观与自然性优先于拓扑/3D特效（R4-M反馈／R4-N方向，2026-09-27）

Henry认可R4-M同主题亮点提供一部分信息增量，但只有已知背景才容易懂；无背景访客看见亮点和当前点，不知其含义，文案教学不能替代直观动作。并且Henry把亮点称为“相似度”，与本机实施“**同名已审核Topic Tag，并非cosine相似度/语义真值**”并不等同。这不是挑访客词语，而是可观察到的映射歧义，应当把“图说了什么”先于“如何解释图”。公开快照仅1,432/3,462条有已审核Tag，缺失不构成负例；旧R4-L无价值的额外线亦不能借此复活。

研究范围允许新2D局部团、群团式3D/Three.js与其他学科灵感，但Henry的抛砖引玉不是生产选型。下一步若做R4-N先给不知背景的人一个原文和它的真实地图点，点击另一个点后出现那句真原文，只有主动点击真Topic Tag才亮对应的其他实际已标注点；无须先记术语。团若存在需显示可以打开的真实成员、书籍覆盖与方法边界，结合R4-A～F已记录的单点/巨块/尺度不稳失败，不能强称拓扑群天然主题。3D要有真实、可核的深度语义或更自然的读句交互，否则只是有遮挡和摄像机成本的装饰，完整2D/文字退路继续保留；线上已有2D地图作为Henry认可的参照。具体预备契约与未做的首次访客任务见`docs/73`；没有选定新算法、3D产品或发布。所谓“更有趣”须与不了解背景也能操作、能读原文、能用自己的话说看见了什么共同通过Gate，工程或Henry单人反馈不能伪作独立首访。

## 5. 每次实验的记录契约

保存数据范围、输入 hash、模型/预处理/度量、算法/版本/seed、全部参数、实际命令、时间/资源成本、输出路径、失败与纠正。分别写：已有文献结论、本站假设、实际观测、解释、未测项目。相同语料上的算法比较不得暗中改变数据或标签。

地名评估先看附近已复核成员支撑、支持成员书籍分布、不同尺度/扰动稳定性；多视图评估看高维邻域保留和虚假邻近、主题内部信息及访客方向感。避免把同一标签同时用作强监督目标和独立验证真值；需要留出主题/书籍、人工核对反例与跨书样本。

邻域大小和指标阈值由探索产生，再在留出的主题/书籍上验证；本轮 15/30/60 不是产品 Gate。换算法后密度图只描述那个新投影的密度，不能横跨不同布局直接比山高。简单坐标线性补间也不是高维观察平面的连续路径证明。
