# R4-G — 路线先于大陆：局部语义漫游试验

日期：2026-09-27，预登记后完成数值与原文检查；允许下一阶段做本机交互观察器，但路线未选为产品算法。R4-E/F 表明不能凭全局簇/地标自动画可信大陆；保留已有向量上的**局部有向近邻**，先问能否从一句原文连续走过不同书籍，并在岔路处看到真实句子，而不是构造一张强制全连通的语义图。

灵感（非移植/新颖性声明）：Coifman & Lafon 的 diffusion maps 从图的多步连接观察多尺度几何（`https://www.sciencedirect.com/science/article/pii/S1063520306000546`）；Paudel & Bernstein 的带擦除随机游走在*不同的*推荐场景寻求多样性（`https://arxiv.org/abs/2102.09635`）。本站只做确定边规则和有限长度的阅读试验，不实现扩散距离、拓扑同伦、多轮推荐学习或有理论保证的随机游走，也不把实验娱乐性称为推荐有效。

## 固定规则与比较

- 复用 R4-E 已核对文本哈希的3462条公开真实划线及原1024维向量生成的前16个**有向**原空间cosine近邻（不是互选才可走）。核对快照/缓存/图artifact指纹，运行时不调模型；路线里的每一步必须是当前句指向下一句的原图前16名，记录实际邻居名次与相似度。不同书优先是强约束：此轮同书候选不算下一步；无跨书候选则在原处终止，不从二维距离、标签或书籍清单补“语义边”。已见句不重用，重复书只在所有合格候选都来自已见书时出现；不能保证全量到达。
- 固定每条最多6跳，按边排名次循环 `近端1–4 → 侧边5–10 → 外缘11–16 → 侧边 → 近端 → 外缘`；在各段中优先未到过的书，剩余若多项用可注入且按起点ID固定seed的PRNG选一个。若该段为空而其他段有跨书未见候选，则从全16项按相同新书规则选并明确记为`bandFallback`，不伪装为完成该段；全无则`deadEnd`。`外缘`仍属于最近16句，绝不解释为语义反对或远距离。对照路径在相同起点及强约束下始终取分数最近的合格跨书句，不使用软节奏，适用可读差异比较而非准确率基线。
- 种子：每本公开书ID排序的**第一条**划线（108个，按书等权、但开头ID并非随机）；再补此前固定5例 `h-3501/h-898/h-2288/h-4504/h-1754`（去重）。报告分开描述108个书起点和固定案例。指标：成功6跳/死路数、每跳候选可达不同书数、路径不同书数、实际rank/score范围、段回退、已复核tag的可见转换只作描述（未标注=未知），以及与最近跨书对照相比的路径重复程度。无像素距离/标签拟合，不通过优化自身指标证明语义好。
- 保存五例及按book ID顺序固定另5个书种子的两条真实原文路线，每步指出从哪句走到哪句、书籍、rank/score与回退；研究者查“词面相似但阅读不好”“弱关联却有趣”“死路”，不把机选轨迹包装为同一主题或人工评分。拒绝公开卷入有争议的句子不影响本机研究；正式发布仍另行 Gate。
- 研究结果如有局部值得读的岔路再考虑本机只读观察器；若前16跨书网络大量死路/同一书反复或文本牵强，则保留失败，不调参到好看。测试纯函数/注入rng、重跑可复现、全测/typecheck/lint/build/隔离。不得改 `src/`、`public/`、生产坐标、地形、公开构建资源或部署。用户R4-D填写不作标注集。

## 运行结果（2026-09-27）

公开已审核3462条/108本，每本第一条真实划线作一个种子，另5个固定例子中 h-4504 与书种子重合，故112个唯一种子。逐条向量原文hash、公开快照/向量与R4-E图指纹通过；不调用模型。按书种子的两种路径各有106/108走满6跳，另外2条在0跳与2跳后遇到**没有跨书未见的前16名**；不能声称全库从任一点都可走。两者按书种子都是不同书中位数7（含起点）；软节奏638跳里32次所需段无候选而如实回退，步骤rank中位8，最近跨书对照中位rank2。两条路径的成员Jaccard中位为0，说明选择产生了*不同文本*，不是哪条更好。软节奏抵达不同终点84个、最近跨书76个；这只是种子重叠与算法结构指标，不是体验多样性胜率。已有108书的首条划线ID不是随机访客起点，且最近跨书对照共用跨书/未见/新书优先约束。

固定原文（研究者非独立判断）：h-2288起点“读世界之书/自我存在”经软节奏转向自我反思、相似情景注意力和确认偏误，出现可讨论的**读法→自我校正**路线，但也可能只是宽泛的“思考”词族；最近跨书对照先到真实书籍阅读方式再转向政治/观念，不能武断判前者优越。h-4504从文化资本/高教筛选出发的软节奏很快跳到“读这本书”“程序员头脑”，更像课程/书籍元词的误导漂移；其最近跨书对照经精英、阶层、财富转到恐惧/金钱，也有较远的跨主题跳转。h-3501软节奏多次流向金钱/理财/期货，并非“恐惧”唯一叙事；h-898软节奏从恐惧/勇气转向交易中的自我控制，而最近路径在阶层/改革之间行进。h-1754软节奏反复回到官场/领导语境，跨书不等于体裁/内容多样。五例以及按书ID前5本的两套完整真实原文路线留在`.private/research/map/route-first/review.json`，死路和所有参数/数值在`study.json`；不摘录未复核的大段原文进公开报告。

**阶段决定**：可达性和局部文本分叉支持做一个隔离、读者可主动择路的本机观察器，以检验“有意思”；没有证明该软节奏比最近跨书更好，也不以模型cosine视为语义准确率。岔路呈现rank/不同书来源的证据但不称语义对立，不隐藏死路/漂移，也不要求 Henry 再标36题。观察器前不改任何线上地图或访客小径。
