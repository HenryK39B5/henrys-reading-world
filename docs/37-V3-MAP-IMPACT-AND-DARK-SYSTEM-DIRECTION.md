# 37 — 地图作品感与全站深色方向：7D 后续判断

> 日期：2026-09-23
>
> 状态：用户认可全深色地图比旧版更有质感，但地图整体冲击力仍不足；亮书弹层细节已局部修复。以下是下一轮视觉探索假设，**不是全站配色 Gate 或新地图数据授权**。

## 当前事实

地图页以 `shell--dark-map` 使用深墨绿地形与暖深灰阅读面；其他房间沿用7A浅色。这是7D局部样板的工程隔离，**不是「最终地图深、其余页浅」的设计结论**。用户此前明确反对手机上的深图浅文硬切，故不推荐把浅色房间直接视作最终统一方案。当前样板、行为与未验收项见 `docs/36`。

## 具体的视觉目标

冲击力不依赖随机精选句、大标题压住地图、彩虹标签、虚构海岸、星空粒子或额外宣传页。访客进入地图时应立即看到有结构的真实地形，并能辨认「点、区域、书」三种尺度；真正打开一处划线时，原文成为视觉中心。地图只使用原有4,663个坐标、56个标签锚点及64×40真实密度场，未标注点只做地形。地图与其他房间能共享深色阅读材质、来源标记及文字层级，但各房间不应沦为相同的深色面板。

三套**同数据、同地图、同动作**的下一轮构图候选（先做静态/局部可交互比较，再决定产品施工）：

1. **地形开场（首选试验）**：地图先于说明和书籍工具进入手机首屏；标题和少量导航退到地图的外缘，地图本身占据主要画幅。地点文字仍是可读的真实标签，缩放/选书可达但不在首屏堆两层控制。桌面上地图作为完整作品展开，进入详情后成为同一张图的伴页。必须验证首屏可见区域不因裁剪而歪曲真实空间。
2. **索引开场**：突出主题地名与语义区域列表，通过排印的密度获得「图集目录」感，地图退居次席。最适合键盘/读屏路径，但视觉上可能再次过于克制；作为对照，不丢弃列表。
3. **从书入图**：选中一本真实书时，来源书封的颜色只作用于它自己的点和来源标记，让散落轨迹自然浮现；默认世界仍是全量公平的地图，绝不默认替访客挑一本书或重排坐标。需要同时验证531点密集书和极稀疏书。

推荐先试1，再将3作为**选书后的状态**，不做彼此竞争的两套首页。视觉张力主要来自地图/文字尺度变化、真实密度层次和清晰的抵达过程；不是持续发光或长动画。reduced-motion下保持同样的信息层级，无空间动画。地图标签需按相同实际锚点检验碰撞、可读性和触达，不做主题色分类。

## 本轮已处理的细节

原 `select` 的弹出列表由系统绘制，即使把闭合态画成深色，也无法保证展开态融入产品。改用原生模态 `<dialog>`：真实书名和作者检索、全书目滚动、明确当前选择、空搜索状态、Esc和关闭按钮返回选书入口焦点；选择仍用原来的 `book=` URL、Book Aura与地图坐标。手机缩放/选书工具并为一排（每个缩放按钮仍有44px高度），地图更早出现在首屏，当前缩放数值视觉隐藏但保留可访问 output。私有实况图：`.private/review/v3-private-atlas/dark-cross-page/after/mobile-book-picker.png` 和同目录下 `mobile-world.png` / `narrow-world.png`。新控件和首屏比例改善了细节，但**不宣称地图整体视觉 Gate 因此通过**。

## 配色结论的边界

下一轮**优先试全站连续深色语言**，而非最终承诺全站同一块墨绿。阅读房间可以用比地图更暖、更安静的深灰层级承载长文；地图的深绿应保留自己的空间身份。浅色版本保留为对照，不在手机导航时突然插入亮纸页，也暂不加亮/暗模式切换。要同时看门厅、书房、小径、目录、地图及分享，才能确定全站规则。须经真实320/390/1440、200%等价视口、键盘、reduced-motion与完整原文验收；Safari、真机和长时阅读另列未验证。

未建远程搜索、推荐、排序或内容筛选。下一步在用户确认构图与全站方向前，先以相同真实数据制作首屏构图比较，再决定是否拓展7D到其他房间。正式public export / push / deploy仍需独立授权。
