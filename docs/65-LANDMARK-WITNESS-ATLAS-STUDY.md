# R4-F — 真实划线地标与见证者图集

2026-09-27 预登记，随后运行：R4-E单层互选图在强边处有大量孤点，弱边处成巨型块；本试验尝试减少*可导航节点数*，但不把尺寸均衡包装成语义质量。结果未成为地图候选，仅本机研究。

灵感来自 de Silva & Carlsson《Topological estimation using witness complexes》：地标间可以由其最近两地标恰是这对节点的数据点“见证”而连接；原论文也讨论随机与 maxmin 地标选择（`https://diglib.eg.org/bitstreams/5cb47409-b08c-48c0-a8c8-7fba44402cfb/download`），GUDHI 的 witness-complex API 以每个见证者到地标的近邻表为输入（`https://gudhi.inria.fr/python/3.10.1/witness_complex_ref.html`）。**这里只实现一维边的自定义阅读图，不实现完整见证复形、同调或有保证的拓扑估计，也不宣称首创。**

固定输入：公开3462条真实划线+已核对逐条textHash的本机1024维缓存，L2归一化、原空间cosine，ID排序，同分按ID。选64、128地标；第一个是前轮R4-E k16图中互选边度数最高的真实点（同分ID），其后在剩余点中取**离最近已选地标最远**者（cosine最大值最低，同分ID），故64地标是128的前缀；书籍与标签不进入拟合。记录是否选了极端离群点，不隐藏。每个非地标划线（见证者）在对应地标集中取最近两个真实地标，分别赋予主/次归属；这对地标之间的边由该见证者支持，保留全部见证ID与两侧cosine。若内容只有一地标，显式失败。地标自身不当见证，避免自我支撑。

不修饰原图：每地标主/次见证条数、书籍数、空地标、最大单书占比、全部见证覆盖与最差的第二近地标相似度；每边见证数、不同书籍数、最大单书比例。报告边的最小见证阈值 `1/4/8` 下孤立地标、最大连通分量/整图分量、跨书支持边数；`>=2` 不同书籍另作可读性诊断，不用书籍硬改边。对共同64地标，比较其原始见证边在64/128两个规模的保留比例；规模不是统计独立性测试。固定五例查原文：每例的主/次地标、其见证边、至少一条高见证与低见证边所列原文，研究者审阅明显词面错配与有趣对照，不预填人为胜率。

失败条件：多数边只靠单本书/重复措辞、无见证地标过多、图重度巨型/孤立、64→128边保留差；不能只以“图好看”宣称语义对。若有尺度适中且原文可读的证据，才考虑独立的本机交互观察器，仍不接公开地图。保留所有参数、运行时间、反例、重跑数值/文本一致性、专项+全套测试；不读/改用户的R4-D填写，不调用远端模型，不发布。

至少8见证时，64地标图为92边/25孤立/最大39，128图为73边/86孤立/最大40；不筛支持时64几乎全部连接（1分量）、128有2分量。最差第二近地标cosine .303/.343，前5%第二近分数不高于约.360/.392：给每条划线强派两个地标会制造牵强连接。64地标的712条边中只有236条在128地标下仍由见证支持（33.1%），不能把新增地标看作原网络的细化而不改关系；这里不是正式持久性计算。

研究者原文核对（**非独立盲审**）：64规模最高支持边 h-043/h-2873 有241位见证、36本书，却把“健全货币/长期合作”和“赌场算牌的间谍体验”作为两个地标，宽泛的金融/风险句落在中间；见证多不能保证地标本身代表一个清楚的阅读区域。最低边 h-4543/h-4590 只有一条与其两端均无可靠明确共同观点的见证。128规模有 h-1595 这种“这本书如何组织”的书籍元叙述被max-min选作地标；h-2288 被分给它与一段有关爱/力量的文学对话，暴露离群点/内容类型问题。h-1754 的两个地标在64/128时也变动，不能将边解释为稳定的人际阶层区域。完整原文和五例两规模的正/反证保留于`.private/research/map/landmark-witness/review.json`。

**结论**：地标—见证图比逐点阈值岛屿更容易定义“为什么有这条边”，但max-min选点会把离群的章节说明和表格碎片当作区域地标，单书边多、规模变化大、主见证严重偏斜。仅保留为内容路标研究启发，**不选作地图骨架，也不建本轮浏览器观察器**；改成更密的图或过滤掉难例不能直接视为解决。若继续探索，先以真实原文辨别“地标代表一个区域”与“片段仅适合当路过的路标”，并对结构/视觉趣味分开验证，不要求用户批量标注。
