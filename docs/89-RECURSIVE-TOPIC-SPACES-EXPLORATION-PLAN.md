## 2. 分形灵感：递归读法，不宣称语料是数学分形

用户抓住的是局部/整体反复使用相似组织方式的直觉。数学研究还会讨论统计自相似，而不只要求形状严格复制；本轮核对Mandelbrot原论文摘要，只用于澄清这个入口。没有检验本站语料的尺度律/分形维数，不能宣称阅读网络天然具有自相似。

Agent建议借用的形式是：**每个主题局部都仍然是一个可以观察、进入、读原文、返回的世界。** 重复的是阅读/组织规则，而不是强迫每一级画成相同形状或无限生成细节。

分形启发主要改变“内容怎样逐层组织”，前三种形态主要改变“空间怎样呈现”。它们可组合，不必变成四个互相竞争的图皮肤：

| 候选 | 主要探索什么 | 与递归空间可能怎样结合 |
| --- | --- | --- |
| 阅读地球仪 | 可转动整体、方位记忆、关联显露 | 选主题后进入局部世界，保留返回原球位置；不先假定每一级必须再造一颗球 |
| 焦点透镜 | 当前材料清楚、周围仍有参照 | 当前主题局部变为焦点，上层留参照；须区分仅放大与真正切换材料集合 |
| 可展开曲面 | 区域进入/展开、局部材料可读 | 展开一个真实局部后显露交叉主题；不凭空造岛/命名 |
| 递归主题空间 | 条件改变后重新组织真实材料 | 为三种容器提供相同可核查的集合/分支输入；是否有有用局部仍需检验 |

“整体的缩小副本”不是硬目标。细小局部可能只适合读原文，不应为了画面持续变化强分群。

## 3. 从哪里获得新的局部：先做两种清楚可对照的研究

### 3.1 基线A：已有复核标签的条件交叉

先不生成新标签。设冻结语料中的原文集合为H，当前已选择的标签集合为S，定义：

```
H(S) = { h ∈ H : S 中每个标签都已记录在 h 的复核标签中 }
H(空集) = H
进入另一个标签U：H(S ∪ {U})
```

这是研究定义，尚未实现。它可直接回答：在当前已记录的主题材料里，还有哪些共同涉及另一主题的原文？每个入口可核查成员原文、出处、书籍分布及共同标签。

关键区别：UI中“主题T里的U”表达**条件下的交叉**，不说U是T的永久子类。Topic Tag仍然地位平等，Book Theme仍是按书分类。同一原文/局部可由多个入口抵达，不强制独占的一棵树。把对象与已记录属性组织成交叠结构，可参考形式概念分析；它只是工具入口，不等于本站已经实施完整概念格或获得语义本体。

未记录标签保持未知，不当作不相关负例。若参考二值形式概念工具，关系只解释为“已记录复核标签的发生”，不能把未标注的0用于语义否定/标签蕴含。已有标签的显示上限1–3也意味着：纯追加标签条件的非空深度有限，不能承诺无限层级。

### 3.2 候选B：在真实局部内观察原空间关系

与“已有交叉标签”并列研究，而非先决定替代它：进入一个集合后，观察已有本机向量/关联图能否显露更具体、可复跑的局部结构。这样可检验尚无交叉标签入口时是否仍有内容增量。

- 对照保留全局图在局部的诱导子图，与在局部重新计算近邻的结果；新增近邻是条件下候选，不冒称全局原有直接边。
- 检验同书主导、泛用句、虚假邻近、孤点/巨团、参数敏感性。聚类不是发现新主题的证据。
- 自动局部若无合适真实标签，不由Agent手工命名/写解释。可研究用实际成员原文作为入口；具体代表选择/分支规则未定。
- 没有可信/有信息的进一步结构时停止组织，直接阅读；不强补节点/边，不重新调用远程模型。

原文全文与ID不变。数学处理会改变可见关系/局部布局，不能说改变了原文意义。

## 4. 候选共同动作（先讨论清楚，不必先选外形）

```
看到一个世界及可读的真实材料
  → 选一处原文：显露少量可预览的关联候选
  或选一个有真实支撑的主题局部：进入该批材料的空间
  → 在局部看原文/交叉入口，选择继续进入或转向
  → 读完整原文与出处
  → 返回刚才的条件、画面和焦点
```

这是Agent提出的共同动作语法，不是新增强制模式切换/参数控制台。将它文字讨论明确后，可分别探索三种容器，不需要先选唯一赢家。

同一批原文与空间条件尽量共享：区分纯视觉zoom、进入更小集合、改变焦点，以及转向另一条件，不能让一个手势同时静默改变全部语义。每一级展示真实材料差异，而非只裁切/缩放全图；如何在视觉上连续而不迷路是核心研究问题。

## 5. 进入与停止的规则必须诚实

- `H(T,U)`与`H(U,T)`的成员应相同，但进入/返回历史可不同。用稳定ID与条件标识空间，保留实际来路，不假定每处只有一个父节点。
- 成员完全一样的候选合并/标记同一局部，不假装产生更深新地图；重复条件、空集合不制造可进入的假空间。
- 没有更小且有信息的局部，或只剩少量材料时，进入阅读而非强分。最小支撑、是否需要跨书、代表数/深度限制均待数据研究，不能为漂亮输出逐案调参。
- 只有当前主题标签的原文仍在当前集合可读，不能因没有更深入口就删除。整个语料中未标主题的原文也保留，不为递归功能补全全部标签。
- 原文、出处、源ID、详情往返与焦点连续性贯穿各层；从不同入口进入同一局部时仍应返回实际入口。
- 展示的是本站已记录材料及模型候选结构，不宣称一套完整知识分类或标签内材料都相同。

第二步采用既有冻结真实输入，不为了样本好看换范围/挑书。实际public/local范围、标签状态、向量覆盖逐轮写清；范围不一致的数值不混为同组比较。没有需要先取新数据/换embedding的结论。没有选本机新模型或新增依赖的承诺。

参照不是只有三个新图互比：普通标签交叉筛选、现行主题小径/地图及简单近邻都应保留为底线。若递归地图只比普通筛选多一点动画，或只放大同一图且没有可读增量，就记录失败/收缩该方向。布局质量、语义关系、阅读价值、视觉吸引力、工程成本分别看，不以编译/数学指标代替其他项。

下一份研究报告应优先回答：**在真实语料里，哪些“再进入一层”真的改变了可读材料的组织，哪些重复/稀薄/无信息？** 不让Henry先替Agent挑算法或给材料制作分类说明。
