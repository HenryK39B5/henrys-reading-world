## 2. 集合对照：从各自最近一句到联合耦合

### 输入和目标

把两本书**已有的划线集合**表示为离散测度，而不是把每本书压成一个均值向量：

- `A={h_i, a_i}`、`B={h_j, b_j}`；每本书总权重1，默认每条实际划线等权。
- 本机已缓存BGE向量归一化，`C_ij = 1 - cosine(i,j)`，本轮采用Float64。
- 输出非负耦合矩阵`P`，不是新写的关系说明。

平衡模型在`P1=a`、`Pᵀ1=b`下最小化`<C,P> + ε KL(P || a⊗b)`。所有行/列共同受约束；一条候选占用目标侧质量，会影响其他候选的分配。这与每行独立取最近邻不同，但底层成本仍来自同一embedding，不是新的语义理解。

不平衡模型移除硬边缘等式，增加`ρ KL(P1 || a) + ρ KL(Pᵀ1 || b)`，采用广义KL：`KL(x||y)=Σ[x log(x/y)-x+y]`。缩放核为`K=(a⊗b) exp(-C/ε)`，更新指数为`ρ/(ρ+ε)`；平衡版指数1。方程与POT官方文档及Chizat等的缩放方法入口相符，源码为本站数值实现，未使用POT库或复现原论文实验。

### 能展示什么，不声称什么

候选动作：读者选两本已有书，看到两组原文的计算分配；点某条或某个候选打开双方完整原文，保留书名/ID/详情返回。不是Agent写“这两书都在讨论某问题”，也不是自动剪三句话成故事。呈现形态尚未选择，不能据此创建隔离手感页或改线上。

风险与停止条件：

- 平衡版即使两组材料差异很大仍要求全部分配，不可把被迫配对称为发现。
- 不平衡版软化约束，但质量不是相似概率、可信度或“某书思想被覆盖百分比”。正核下本版矩阵仍稠密；非零项不等于确有语义关系，尚无可发布稀疏化/不连接规则。
- 每本书划线多少不是完整思想分布；两条划线也不能代表一本书。等权、成本尺度、ε/ρ都影响输出。
- NN目标更分散、耦合换了候选、目标函数更低，都不是阅读收益。
- 跨段不可约意义另需可执行目标与零模型；不能把成对联合分配重新命名为高阶语义。

四书81条原文形成6对；对每对运行`ε={0.02,0.04,0.08}`，分别平衡及`ρ={0.1,0.3}`不平衡，共**54次实数值求解**。输入校验覆盖3,462条公开原文的实际textHash与1,024维向量；未对全部108本的所有书对求耦合。

在`ε=0.04,ρ=0.3`切片，6对共43次源行选择中29次最大耦合列不同于独立NN。这里43不是43条独立样本，同一源句会在不同书对复用；不作显著性或胜率。平衡版为33/43。

例如b-055→b-028，23条源行独立NN落到6条目标原文，平衡最大耦合落到21条，不平衡最大耦合落到19条；不平衡有16/23行更换候选。这说明联合约束确实改变分配，不说明新候选更好。`ε=0.04`时ρ=0.1总耦合质量约0.043–0.095，ρ=0.3约0.306–0.408，敏感性必须保留，不能随手选一个数作关系强度标准。

## 3. 条件通路：同一网络，不同起终点得到不同观察函数

### 固定输入与可计算的“情境”

复用R4-E缓存的**公开真实划线互选top16余弦图**：3,462节点、10,278条无向边，不用生产二维坐标，不补边。令正边权`w_ij = cosine(i,j)^4`，`d_i=Σ_j w_ij`，转移矩阵`P_ij=w_ij/d_i`，显式固定平稳混合测度`π_i=d_i/Σd`。这是人为定义但可复跑的模型随机游走，不是读者真实轨迹或作者思想过程。

起终点集合A/B由选定两本书的真实划线组成。求committor：

```
q_i = 0                         i属于A
q_i = 1                         i属于B
q_i = Σ_j P_ij q_j               其余有边界条件的节点
```

明确采用“先到B而非A”的约定。可逆无向网络中，反向committor为`1-q`；TPT净通量化简为`f_ij⁺ = (w_ij/Σd) max(0,q_j-q_i)`。同样的节点/边在换A/B后有不同势和通量；变化的是**条件观察结果**，不是Agent替原文换一个解释。

候选动作：读者指定起点/终点内容，查看计算出来的中间原文、分支与其真实出处，自选打开全文。不是第二个自动逐句漫步引擎，不自动宣称“从经济到人生”的故事或起飞镜头。此动作仅为文字候选，未获选为新核心界面。

### 前提和反例

- 此简化净通量公式依赖对称正边/详细平衡；不能原封不动套到旧有向近邻游走。
- 图边仍是embedding候选；势/通量不代表语义进度、因果、论证、支持/反对或适用条件。
- 只有A的连通分量q=0、只有B的分量q=1；两者皆无的分量缺少本次Dirichlet边界、谐和问题非唯一，研究输出按未锚定保存`null`，不乱填0.5或强接弱边。无通路就保持无通路。
- 模型平稳权重依赖加权度数，不是按书公平的消费者抽句规则。大量划线/高度节点、泛用词面句可能主导通量；数值通路不能自动取得产品公平Gate。
- 上下文是显式选择的A/B，不是语义情境自动提取。若要求生活场景/论证角色，需要另一套可靠提取流程；本轮没有实现。

### 实际结果

同样的4书生成6个条件，全图求势/通量；额外反向求解第一对作控制。本图182个连通分量，其中170个孤点；6个条件均有1个同时触及A/B的分量，各有**194节点没有本次边界锚定，保留null**。不能把这些句子说成与所有书都无关。

6个条件谐和残差小于`1e-10`，内部净流守恒和起终点通量平衡检查通过；反向条件`q_AB+q_BA=1`最大数值误差约`5.77e-15`。这些是模型数值控制，不是阅读效果。不同条件最强12个中间候选覆盖3–9本书；包含集中现象，暂不靠调参数或人工替换改善。

## 4. “结构相似”与语义相似的严格区别（尚未实现）

可执行的较弱候选是Gromov–Wasserstein：对每本书的已有向量集合构造内部距离`D_ik=||u_i-u_k||₂`，再最小化`Σ(D_Aik-D_Bjl)² P_ij P_kl`，有平衡边缘约束。它比较**两组内部关系能否对应**，不必以跨书`cosine(i,j)`作匹配目标。Fused GW则显式加入跨组特征成本及混合参数，不能把它说成完全脱离语义特征。

这回答了算法层面的不同，但没有解决哲学结构类比：内部距离来自embedding，就只是在对齐关系轮廓，不会自动识别“决策困境/因果链/信任结构”。相似形状可能只是同样疏密、数量、体裁或向量各向异性。若要因果/角色图，应先定义固定解析器、跨度定位、否定/条件作用域、失败留空，再将所得关系作为输入；这些提取模型尚未选择或运行，不借GW替缺失的关系背书。

后续可用的失败测试：对其中一组作正交变换，内部几何不变而跨组余弦可能变化；纯GW不应因此改变结构目标。还须检查置乱/近等距轮廓、非凸局部解和对称形状的多解。数值最优不等于真实类比。首轮九处人工读例保留为旧探索，不拿来训练这次对应关系或充当独立验证集。

另一个未实现候选是嵌套随机块模型/最小描述长度：在固定输入图上联合选择分组及层级复杂度，降低手挑群数的依赖。但其结果是模型图的统计组织，不是自动产生真主题；原图边的偏置仍在。不为上高级名词同时开四套UI/新群落命名，不宣称已训练SBM、sheaf、群表示或找到新数学工具。
