# 12 — Critique #2：房间、色彩与呼吸感

> 状态：2026-09-13 用户确认的最新空间与视觉方向。
>
> 历史权威：本文件记录 V2 房间、Book Aura 与呼吸动效基线。**2026-09-18 起，V3 视觉重构以 `docs/21-V3-VISUAL-DIRECTION.md` 为最新权威；房间 URL、颜色归属、返回现场、文字中心与 reduced-motion 原则继续有效，具体外观、主题小径和世界地图允许重新设计。**

## 1. 本次反馈与判断

用户认可当前页面的审美 taste、文字排版、真实封面与克制气质，但认为整体仍显“苍白”。问题不是纸张底色太浅，而是颜色主要停留在封面内部，页面没有形成与当前浏览对象一致的环境温度；同时，舞台、书籍、主题与 About 全部排在同一张长页面上，使不同层级只有内容区别、没有空间区别。

新的方向是：

> **把阅读世界组织成可以轻盈进入、自然返回的一个个房间；颜色属于当前房间与当前书，动效提供呼吸感，但不把产品做成拟物书房或视觉表演。**

“房间”首先是信息架构和状态边界，其次才是视觉隐喻。纵深来自一次只让一个层级成为主角、返回时保留现场、颜色有明确归属，而不是 3D、视差或复杂转场。

## 2. 空间结构（已确认）

### 2.1 门厅 `/`

默认的 `随便看看` 舞台，只保留：

- 当前一条真实划线、出处与原位展开；
- `再来一句`；
- 低权重入口：`逛主题书架`、`看看所有书`、About；
- 当前 all/theme stage scope 的必要状态提示（主题 scope 的具体 UI 在主题房间内）。

门厅不再向下铺完整书籍、主题、年份和 About 长页。它是阅读世界的入口，不是内容总览。

### 2.2 主题书架 `/themes`

展示 8～15 个书架入口。每个书架显示：

- 平实标题与说明；
- 真实 `N 本书 · M 处划线`；
- 最多 3～4 张真实小封面，或由这些封面形成的窄书脊色条。

点击主题进入独立主题房间，不在列表下展开 10～12 条划线墙。主题不使用人为规定的固定语义色（例如“政治=红色”）；颜色只能来自该书架内真实封面。

### 2.3 主题房间 `/themes/:id`

采用用户确认的“安静阅读室”方案：

- `正在逛：<主题>`；
- 平实说明：划线来自这个主题书架中的书，不声称句子本身属于主题；
- 一次显示一条真实划线；
- `再来一句` 持续停留在该主题；
- `看看书架里的书`、`换个主题`、`回到随便看看`；
- 出处与临时书内换句继续可用。

主题房间是持久 stage scope 的空间表达，不是主题文章或策展结论。

### 2.4 所有书 `/books`

独立书库空间：

- 初始显示 10～12 本，之后每次追加约 20 本；
- 默认按最近留下真实划线的时间排序；
- 年份是低权重的书籍筛选，只影响书库和打开的单书顺序列表；
- 暂不做搜索、评分、排行榜与复杂排序；
- 真实封面是主要色彩来源，不铺统一大色块或首屏封面墙。

### 2.5 书籍房间 `/books/:id`

一个明确属于单本书的空间：

- 较大的真实封面、书名、作者与真实划线数；
- 一处随机真实划线；
- `随机看一处`；
- 全部划线按 8～12 条起始、每次约 20 条分批展示；
- 返回之前的主题房间、所有书或门厅，并恢复进入前现场。

书籍房间可以比其他房间使用更明显的封面取色，因为颜色归属唯一明确。

### 2.6 About `/about`

小而独立，只保留真实收藏范围与可选的 Henry 自写介绍。不要在访客页面解释内部非目标、防御性原则或发布流程。

## 3. 导航与现场记忆

房间使用真实、稳定的 URL 层级；视觉上仍属于同一个阅读世界。

推荐路由：

```text
/                   门厅 / 随便看看
/themes             主题书架
/themes/:themeId    主题房间
/books              所有书
/books/:bookId      书籍房间
/about              关于
```

行为要求：

- 浏览器返回键与页面返回动作结果一致；
- 从主题进入一本书，返回后恢复原主题、原句与必要的滚动位置；
- 从所有书进入一本书，返回后恢复已展开批次、年份筛选和滚动位置；
- 刷新后仍能从 URL 恢复当前房间；无效 ID 给出安静、可返回的错误态；
- `NEXT_IN_BOOK` 是临时书内动作，不改变持久 all/theme stage scope；
- 返回门厅不应无故重抽一句；
- 后续分享仍以稳定 highlight ID 作为内容身份，房间和 scope 是上下文，不替代 highlight ID。

路由可在 V2-C1 实现；V2-B 先把纯状态和 scope 语义做对，不提前重写 UI。

## 4. 色彩系统：Book Aura

### 4.1 颜色归属

颜色不是装饰贴纸，而是当前空间的环境线索：

- 门厅：当前划线所属书的封面色；
- 主题书架总览：中性纸色，颜色来自各书架少量真实封面/书脊；
- 主题房间：稳定的中性基础温度 + 当前书的局部活动色；
- 所有书：中性纸色，真实封面负责主要色彩；
- 书籍房间：当前书封色，浓度可最高；
- About：中性纸色。

主题不分配人为语义色。若未来尝试从书架封面计算综合色，必须先生成 14 组实际截图 review；综合色发脏、含义不清或变化过大时，主题基础色保持中性。

### 4.2 推荐强度

以现有 `--paper: #faf9f6` 和封面 muted accent 为基础：

- 门厅纸色混入当前 accent 约 4%～7%；
- 主题房间局部活动色约 3%～6%；
- 书籍房间约 8%～12%；
- 文字正文继续使用高对比墨色，不直接染成封面色；
- accent 继续用于出处下划线、焦点、细边界与低权重操作。

目标：第一眼看到文字，第二眼感到颜色，第三眼才意识到颜色来自书封。

### 4.3 分享卡片的 Book Aura 例外

房间继续遵守低浓度环境色；分享卡片是 dialog 内独立的出版物预览，可以使用更深的大面积色域，但仍必须来自**锁定划线所属书籍**的真实封面 accent：

- dialog 是浅色纸面，卡片是低饱和深色有色纸面，两者明确分层；
- 不显示封面图片，只使用其 muted accent；无封面回退 `DEFAULT_ACCENT`；
- 暖色文字、出处、品牌和细框都需达到可读对比度；
- palette 与 stable highlight ID 一起锁定，不能继承可能变化的当前房间 Aura；
- 只用一个稳定出版卡片系统，不做固定黑金、头像、日期、统计、二维码或随机模板；
- 仍只是 CSS DOM 预览，不在本阶段导出图片。

完整实现与 Gate 见 `docs/16-V2-E4-SHARE-CARD-VISUAL-IMPLEMENTER-PROMPT.md`。

### 4.4 禁止的视觉做法

- 不做整屏高饱和渐变、主题大色块或每个主题一张彩色 Dashboard 卡；
- 不做 130 本封面的首屏拼贴或装饰性封面墙；
- 不让相邻换句造成背景猛烈闪色；
- 不给主题建立“政治=红、文学=紫”之类人为语义色；
- 不用随机彩色光斑、玻璃拟态、霓虹、噪点或通用 AI 网站式渐变替代真实封面色；
- 不牺牲正文和控制项的可读对比度。

## 5. 呼吸感与动效语言

呼吸感主要来自留白、节奏、一次只显示一个中心，以及轻盈的进入/返回。避免持续漂浮的文字、按钮与封面。

### 5.1 房间进入与返回

- 内容从约 8～12px 的轻微位移中淡入；
- 主过渡约 320～420ms；
- 环境色约 600～900ms 缓慢接续；
- 标题、句子、操作可错开，但间隔不超过 80ms；
- 返回使用克制的反方向提示；不做门扇、3D 透视、缩放穿越或视差滚动。

### 5.2 换一句

- 原句轻淡出，新句原位淡入；
- 颜色变化慢于文字变化；
- 连续快速点击只提交最终有效状态，不叠加颜色动画；
- 不模拟翻牌、抽卡、老虎机或机械翻书。

### 5.3 首次进入

用户确认采用短暂“空间醒来”：

- 先出现纸张底色；
- 约 300ms 内句子自然出现；
- 当前书环境色在约 700ms 内进入；
- 只在首次进入房间或真实房间切换时发生；
- 不增加启动页、Logo 动画或 loading 文案。

### 5.4 静止状态与 reduced-motion

第一版不做永久循环的背景呼吸动画。先通过静态空间、颜色层次和有触发条件的过渡获得呼吸感；截图 review 后仍显僵硬，才单独评估 12～18 秒、极低幅度的环境色变化。

`prefers-reduced-motion: reduce` 下：

- 取消位移、错峰与长颜色过渡；
- 状态立即准确提交；
- 焦点与浏览器返回行为不变；
- 不以“几乎为零的动画时长”隐藏仍会闪动或位移的实现。

纯 CSS 能完成的过渡不用动画库。

## 6. 响应式原则

- 移动端每个房间仍只保留一个视觉中心；不把桌面侧栏机械压成顶部工具条；
- 房间入口、返回与 scope 操作保持至少 44px 触控高度；
- 390px 下封面和色晕可以更靠近内容，但不能挤压句子阅读宽度；
- 长划线继续使用既有短/中/长排版带，不能因为环境色而降低文字对比度；
- 320 / 390 / 768 / 1440、200% 缩放、键盘与 reduced-motion 必须作为最终主路径验收。

## 7. 更新后的实施切片

```text

V2-B   公平发现引擎与 all/theme scope 纯状态（已完成并通过复验）
下一连续批次：V2-C1 房间路由与现场记忆 → V2-D 全量分批浏览 → V2-C2 Book Aura 与呼吸动效
```

连续批次纪律：

- V2-C1 先证明导航层级、返回和状态恢复正确，允许继续使用低色彩版本；
- V2-D 随后补齐所有书与单书的真实全量分批浏览，不回退成同时渲染 130 本或 4,663 条的长墙；
- V2-C2 最后在完整房间内容上调色与动效，以真实 1440 / 390 截图、299/398 字长文本和 reduced-motion 验收；
- 每个内部阶段独立测试、浏览器验证、记录和 commit；Gate 通过后直接继续，不为常规事项暂停。

## 8. 本轮成功标准

- 门厅、主题书架、主题房间、所有书、书籍房间和 About 的职责一眼可理解；
- 用户感觉是在同一个阅读世界中自然进入不同房间，而不是在一张超长网页中寻找折叠区；
- 返回后现场仍在，浏览器行为可信；
- 色彩增加温度和真实书房感，但不抢走句子、不制造主题人格解释；
- 动效轻盈、有呼吸感，又不会持续吸引注意或在快速操作时闪烁；
- 真实材料、公平、防重复、全量可达与低 DOM 密度继续成立。
