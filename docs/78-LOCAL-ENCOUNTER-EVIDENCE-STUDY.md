# 78 — 本机地图「跨书相遇」有效性研究：预登记与实况

日期：2026-09-28。状态：**先预登记，后完成一次本机真实语料试验；未选生产替代方案**。Henry已肯定当前真实地图「看到附近书 → 自选另一本 → 读该书离①最近的真句」带来的信息增量，也要求别让页面靠免责声明自证诚实。本轮试探是否能在**不损失已有主动探索与空间方位**的前提下，使跨书原文的对照更值得读。零结果即保留本机现行地图作为下一次上线的候选；这里不授予push/部署、公开数据/坐标或在线算法变更。现行地图见`docs/77`，先前 R0–R4 的失败、反例和边界见`docs/54–73`。

## 灵感核对：哪些是视觉语言，哪些能成为检验问题

- Henry提供的[抽象代数动画源码](https://github.com/AnctyEnly453/abstract-algebra-promo)以HTML Canvas/WebGL动画呈现抽象代数，另含E8根系投影参考数据。[线性代数动画源码](https://github.com/guchang233/linear-algebra-promo)包含向量变换、特征向量和PageRank的动画章节。两者是表达数学的示例，**不是**针对Henry真实划线建模的论文或效果保证；不能因可旋转/可连线/有E8而声称相邻文字有结构。
- 可借鉴的原则是**在变换观察方式时保留同一句/同一本书的身份**，并把坐标、向量和书籍选择视为不同条件。既有R2–R3已实验过多观察投影，R4-E的互选图出现单点海/巨块、R4-L星座/书岛未获得信息价值；因此本轮**不先做另一张漂亮图或PageRank漫步**。PageRank原论文的链接图有明确定义的边；划线之间不存在这样的引用图。跨书对读更像信息检索中的条件化择句：原始[MMR工作](https://aclanthology.org/X98-1025/)提示相关性与新颖性是两个目标，本研究只借用「不要把接近当作唯一价值」的问题意识，不复制公式或把cosine当读者评分。
- 从空间点模式的**有标记点与受控对照**借用方法意识（参考[Spatial Point Patterns作者站](https://book.spatstat.org/)）：在**同一本被读者选中的书、同一个可见圆**里比较择句方法，不能把两个方法使用不同书籍或不同窗口产生的差异算到「语义」上。不是宣称执行了完整空间统计模型或显著性检验。

## 冻结输入与问题

- 语料：仅现有`src/data/public-snapshot.json`的108本、3462真句及**发布点位**，本机已有`Xenova/bge-large-zh-v1.5@a48549b-q8-cls` 1024维向量缓存作离线诊断。必须验证每句原文的textHash与ID，记录两文件字节SHA256、代码指纹、Node版本、参数与失败；绝不重新抓取或发送远程模型。向量、逐句实验和完整原文仅进`.private/research/map/local-encounters/`，脚本不导出至前端。
- 一个真实访客动作 = ①一条真句；当前页面圆形窗口固定`MAP_READING_ZOOM`上方4倍、720×520视框、当前`MAP_READING_RADIUS`；从邻近书列表选**前两本其他书**，分别在该书**本圆内**候选中选②。每本公开书最多选两个由固定seed与书ID决定的起点，避免多划线书支配样本；手记此前`h-025`共有词、`h-2288`漂移、`h-3501`窄题、`h-4504`长跳及`h-043`死路作为事前反例检查（若不符合本窗口条件明确记无法比较）。
- 同一①、同一自选其他书、同一圆内至少2处其他书的有效样本上比较：**A现行发布图2D最近**；**B同书同圆内原向量cosine最高**；**C该书该圆内按固定seed均匀随机**。单条书也保留计数但三法必相同，不算B提升。几何相同/ID相同在统计中单独报告，不能拿同一个②的cos差称胜出。B只能作为本机观察器中的比较，不自动替换消费者规则；B对cosine的改善是**定义上的优化，不能当独立效果证据**。
- **尺度不变性核对**：取同一锚点和zoom=4，在720×520、390×520、320×500三个地图Canvas尺寸下重算圆内真句ID集合与前两本其他书。现行圆屏幕半径与屏幕比例都按`min(width,height)`缩放，理论上换宽高比不应变成员；实际差异如实记边界舍入/实现问题，不借动画的对称性比喻证明语义。
- 测量一：A相对于同书同圆随机C的模型相似和共享已审核Tag比例，仅后者**双方确有reviewed**才有明确分母；缺Tag是未知而非不相关，审核标签又曾由本机embedding辅助，不是独立语义真值。测量二：B相对A有多少案例换句，原地图实际2D距离增加多少，具体看是否离开可见圆（不允许）；按书计均值/中位、稀疏/拥挤以及起点是否有Tag分层。测量三：事先固定三组原文审阅槽位：B相对A模型增幅最高的4例、A/C差异最小的4例、五个固定历史案例记录状态、其中前四例作详细原文审阅。公布完整对照ID/原文于私有报告，Agent只作注明非独立的原文判断：是否仅换术语、是否保持不同书、可否读出具体对照或分歧；至少保留反对案例。不是为了帮B选漂亮故事。

## 退出条件与后续

输出必须同时列样本丢失（公开缺ID/向量、无他书、其他书仅一条、双方Tag未知）和三法分层；至少一种「更像但更无趣」或「地图近却读出有趣对照」反例原文必须保留。如A已在多数可检查案例优于随机，或B只是重复术语/改变方位却缺乏原文增量，就保持现版、不做新消费者入口。如B在若干案例里真有可重复的阅读收益，再提出**由读者自选**的小范围下一步；仍不能仅凭cos/Tag自动更新生产站。没有自然可读的结果时可停止研究，考虑现行本机完整站点作第二次上线候选，部署需另行决定。
