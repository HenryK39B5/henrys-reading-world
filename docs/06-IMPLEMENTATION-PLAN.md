# 06 — 施工切片与验收

规则：每片完成后执行可用检查、真实浏览器体验、写回执行记录，再做下一片。缺工具 / 数据明确 blocked，不伪造通过。数据审批不是可以用 mock 消除的依赖。

## Slice 0 — 工程与真实数据入口

**输入：** 全部开发文档、当前目录、已移植 skill。

任务：

- T00 检查现有文件与环境，逐文件建立 React / TS / Vite，保留产品文档和 skill。
- T01 配置 lint / test / 类型检查、锁文件、npm scripts、仅 loopback 的开发服务器与敏感路径 deny。
- T02 实现 `03` 契约、严格校验和索引，缺快照时真实空状态，不内置 fake 内容。
- T03 全部书籍（含私密阅读）的开发读取许可已获批准。按 `09` 完成概览分页、分批读取真实划线并记录可续取进度，无 6 本上限，不需再逐书申请；先整理出 30–50 条真实开发样本，不必等全部详情下载完。
- T04 当前直接采用 `02` 的 local-only 路径建立真实开发快照，不再等待用户逐条审核本机使用。正式公开前再确认清单并导出 public 快照；不要过度建设两条数据系统。

**验收：** 工程骨架启动；默认不暴露 `.private` / 密钥；从已获全书授权的范围取得真实划线后进入带内容的 Slice 1。

**Slice 1 执行结果（2026-09-12）**：T10–T12 完成。真实舞台、四入口导航（三个待开放项标为不可用）、三档真实排版、160/280ms 转场状态机、快速连点防重入、reduced-motion 即时切换、单一 aria-live 区域均已实现并用真实浏览器验证。

## Slice 1 — Quote Stage

任务：

- T10 轻量品牌、四入口、舞台、出处行和换句控件。
- T11 用真实短 / 中 / 长 / 换行文本调三档排版。
- T12 转场状态机、rapid-click 防重入、reduced-motion；暂用真实集合顺序轮换检验手感，下一片替换算法。

**验收：** 桌面 / 手机不溢出；原文完整，长句可滚动；连续快速点击不闪烁、不叠字、不抢焦点；无自动换句。

**测试：** reducer 提交计数、卸载清理、reduced-motion；真实浏览器 20 次快速点击。缺某长度真实样本时记录覆盖阻塞，不造句。

**停止修复条件：** 文字不是首屏中心、移动可读性差、转场布局剧烈跳动。

## 完成定义

一个 Slice 的 done = 功能实现 + 对应测试真实执行 + 关键浏览器场景验证 + 已知缺口记录。不得把“代码已写”当 done。

本机原型工程可交接 = Slice 0–5 的本机路径完成且无未声明高风险缺陷；应明确列出 public 构建 / 发布前检查尚未执行，不因此等待公开批准才施工。产品 Gate 通过 = 真实审核样本 + 用户 / 访客体验判断。前者不自动推出后者。
