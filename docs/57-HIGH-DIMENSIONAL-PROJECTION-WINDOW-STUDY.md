日期：2026-09-26

## 固定问题与语料

冻结公开 snapshot 的全部 3,462 条及既有本机 `Xenova/bge-large-zh-v1.5@a48549b-q8-cls` 1,024 维缓存。逐 ID 检查原文 hash、维数、有限性和非零范数；解析既有缓存文件，但只有公开 ID 的向量参与计算。不调用取数/推理/API，不换模型，不改原文、标签、公开坐标或地形。

旧发布地图由 4,663 条生成后过滤而来；作为访客对照，不冒充与新布局同拟合范围的算法实验。另在公开范围复跑既有 RP96 + UMAP 参数（24 neighbors / minDist .14 / spread 1.25 / 350 epochs / 既有 seed），分离拟合范围因素。所有数值指标在相同公开 ID 集内计算。

固定 foreground 为 R1 困难主题：恐惧 tag-026、意义 tag-031、阶层 tag-050。这是有意选择的开发案例，不代表总体。background 为当前未含目标已复核标签的所有公开点，包含未标注以及可能实际含目标的片段；不能称负例。R1 留出结果已揭示，不将其再称 R2 未见样本。

## 方法和预处理

- 原始缓存按行 L2 归一化；参考高维度量为 cosine。同一查询排除自身 ID，但保留重复/同坐标真实记录；稳定 ID 破 ties，并记录完整边界 ties 的敏感性。
- 96 维：复用生产 `projectForMap` 和 cosine。用于诊断预处理，不是假装完整原向量。
- 全局 PCA：公开范围 1,024 维居中样本协方差，使用 `ml-matrix` 对称 EVD，特征值降序，特征向量最大绝对分量符号固定；不做 feature scaling/whitening。保留前 64 个 PC 供 cPCA；记录解释方差与原高维近邻保留，不能忽略截断代价。PCA64 参考距离为欧氏（居中后的向量不能再假定 cosine 与欧氏等价）。
- 全局观察平面：PC1/2、PC3/4，以及 0/30/60/90 度的正交转动：x=cos(theta)PC1+sin(theta)PC3，y=cos(theta)PC2+sin(theta)PC4。列正交，是真实线性观察平面；不是任意二维坐标补间，不称 grand/guided tour。
- cPCA64：在相同全局 PCA64 子空间里对 foreground/background 分别居中，用样本协方差 `C_fg - alpha*C_bg` 的前两个特征向量。alpha 预先固定 0/1/3，不做自动 spectral selection。alpha=0 是主题成员 PCA，不是全局 PCA。对全体点用同一全局中心投影，使各组共享坐标原点；不把组均值平移当聚类分离。
- cPCA 的中心化/样本协方差/对比特征问题核对了作者 `abidlabs/contrastive` 的 README.rst 与 `contrastive/__init__.py`（commit f0d3c330009cfdc76675f95859e70dc96adc3689）。此处全局 PCA64 预处理与作者库默认逐组中心后拼接 PCA1000 不完全相同；数值 EVD 使用维护中的 `ml-matrix@6.15.0`，不自写 eigen/SVD。alpha 固定是探索而非发表复现；Nature 正文仍未核对。

## 冻结查询与指标

每本公开书按 SHA256(`r2-book-query-v1:` + highlight ID) 选 1 条查询（108 本），追加 3 个 foreground 各自 R1 local-density/book-capped 的真实代表点，去重。这是按书覆盖抽样，不是随机句子总体估计。冻结选择代码和预登记后执行，不按图像挑案例。

所有查询 k=15/30/60 计算：高维 cosine 参考邻域与各表示/平面的交集比例、投影邻居的高维 rank、中位 normalized rank、位于高维 top10% 之外的比例；另看固定 30 及完整 ties 的敏感性。两边邻域相同 k 且互斥自身时 recall 与 precision 数值相同，因此不伪装成两个独立指标；未保留的邻居不等于语义假朋友。单书/未知/标签重叠单独描述，不用同一 foreground 标签来证明 cPCA 的语义成功。

原文证据预先选 3 主题的 2 类 R1 代表点；每查询输出高维/旧图/主题 alpha1 平面各最近 5 条（包括所有标签、出处），完整对比而不只挑好看邻居。另对两个恐惧代表点记录原高维距离/rank与近邻交集；没有充分证据不宣布两个真实语义簇。

## 本机观察器与验证要求

产物在 `.private/research/map/projection-window/`，含输入/缓存/算法指纹、参数、报告、原文包及仅含低维坐标/公开原文的观察器数据。浏览器不接触高维向量，不实时跑模型/矩阵，不进入公开构建。

观察器保留同一句的稳定 ID，可切旧图/公开 UMAP/全局 PCA/三主题 cPCA、固定 alpha、PCA 平面角度，查看原文与两类近邻并返回原观察窗口。只画真实点，不给新地形贴名称或比较山高；选中句子始终跟踪。桌面及 390/320px 检查 Canvas 非空、稳定选中、键盘列表、无横溢出、无远程请求、资源隔离。先保留数值/原文反例，再做截图；用户没有认可之前不整合产品。

## 第一轮结果揭示后的补充预登记

首轮全局 PCA64 只保留 53.293% 方差，全局 PC1/2 为 8.733%；主题平面不以全局邻域为目标，不能仅按全局数值否定。为检验截断影响与主题内部用途，先固定下面新增分析，再执行；它们是结果揭示后的探索，不冒充原先预登记或独立验证。

- 同 3 个 foreground/background，用原始 L2 单位向量的完整 1,024 维 cPCA、固定 alpha=1 对照 PCA64 版本；用全局均值作为所有点共同原点。仍不搜索最好看的 alpha。
- 对每主题所有已复核成员，比较原始 cosine 与各平面在该主题成员集合内的 k=5/10 邻域。成员身份用于限定任务，不据成员聚集宣布语义成功；小主题随机交集基线为 k/(n-1)，报告 chance-corrected recall，并保留原始数值。训练/评估用同批成员，是样本内结构诊断，未来仍需留书/独立文本评估。
- 复核发现最初公开 UMAP 对照使用原始输出，而线上坐标已做逐轴 1% clipping/取整。补保留同一次拟合的原始输出与生产 `normalizeMapPoints` 版本，避免把拟合范围变化和坐标后处理混为一谈；公开 snapshot 的 ID 顺序经验证本来就是稳定字典序，没有额外重排差异。这是控制变量修正，不按邻域成绩选归一化参数。

### 3. 主题内部任务：不同案例结果不同

所有目标已复核成员作为查询/候选，仅比较同一成员集合的原1024 cosine和各平面 top10。用训练成员作结构诊断，不是留出预测。随机交集的期望保留率分别为25.6%/35.7%/47.6%，小主题的高比例不能与大主题直接比较。

| 恐惧 / 40 | 45% | 50% | 45% | 40% | 25.6% |

### 4. 完整原文证据包审阅（Agent定性）

完整读取571行固定角色原文包：6角色×4表示×5近邻，意义重复角色对应相同ID，所以不是120个独特句子。前5原文只是局部证据，不代表全书上下文；未知/其他标签仍不是确认负例。以下同时保留成功与失败，而不按效果更换代表点。

- 恐惧两个代表 h-3501（财富/欲望语境）和 h-898（面对人生的选择语境）的相互高维rank为53/318，cosine距离0.4589，top30共享5点。距离是对称的，rank受各自邻域影响。两者的原始近邻确有不同语境，但都能接到 h-3515 等关于恐惧的讨论，不能据此命名两个断开的簇。
- 恐惧完整cPCA中，h-3501全局top30保留从14/30降到9/30；h-898从2/30升到7/30。后者新近邻含反抗荒谬/内在自由等可读关联，也混入时间资源片段。单个视角没有同时改善两类语境。
- 意义 h-2288 原高维近邻有主动阅读、理解作者、觉醒等讨论。PCA64 cPCA的最近邻可出现高维rank2349/1972/3424的明显混杂；完整cPCA找回 h-2349（rank6），但仍有rank1826/3323的声响/地狱等片段。全局top30保留当前4/30、完整条件3/30；不能以一个好例子宣布解决。
- 阶层教育出路 h-4504：当前前5 rank1265/2/885/3/934，完整cPCA前5为2/1/3/8/4，文本同属教育筛选、家庭文化资本、自我认同；top30保留3/30→11/30。前5均来自同一本书，既可能符合局部语义，也需检验书籍措辞/来源效应，不能当跨书收益。
- 阶层人际边界 h-1754：原高维近邻有阶层接近和官场关系，但完整cPCA前5 rank1322/712/86/511/749，仍混入照镜/情绪/谈话片段。top30仅1/30→2/30，是同主题中的反例，不因教育案例更好而删除。
