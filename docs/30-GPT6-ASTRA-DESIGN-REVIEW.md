# 30 — Henry's Reading World 产品与艺术指导审阅

> 审阅对象：V3，产品实现基线 `bee0ad9`；审阅材料基线 `0856587`。
>
> 性质：设计建议，不是已批准的施工规格。没有修改产品代码、内容、标签或发布状态。
>
> 方法：阅读主任务书与 V3 方向材料，查看真实截图，通过本机 Chromium 操作消费者产品。报告不声称审阅执行模型一定是 GPT-6 Astra；文件名沿用任务约定。

## 一、结论：有阅读气质，尚无足够鲜明的世界身份

**当前版本是一个完成度较高的安静阅读工具，尚不是一件经过完整艺术指导的个人阅读作品。**

这不是要求它更华丽。恰恰相反，下一轮应该减少解释与界面框架，让文字、书籍色彩和地形之间建立更强的构图关系。

### 八个核心判断

1. **最成功的是对文字的尊重。** 正文没有被书封、数据和功能卡片挤掉，真实长文仍完整。这是不能为了“视觉升级”破坏的资产。
2. **最大的审美瓶颈是相同模板承担所有空间。** 暖纸、宋体、横线、灰字、pill 和页尾出口在多数页面重复。“房间 / 小径 / 世界”的差别目前更多由文案说明，而不是由空间组织表达。
3. **纸已经成立，墨有基础，光缺少位置，地形仍露出算法骨架。** Book Aura 往往是整页底色变化；地图的方格、阶梯状轮廓和标签底板使它仍接近技术可视化。
4. **克制不是问题，没有明确的强弱决策才是问题。** 多个低权重元素叠加，仍会占据大量首屏空间。移动地图尤其如此。
5. **分享卡片是最接近“设计成品”的部分。** 深色书籍色域、完整边框、正文与署名层级形成了明确对象感。不要把浅色世界也做成卡片，而应借用其精确的比例关系。
6. **小径在交互语义上成立，在视觉上仍像目录加阅读页。** 56 条同节奏条目没有构成探索邀请；“纯公平 / 有呼吸”却在进入阅读前获得了较强位置。
7. **地图最有辨识潜力，也最需要重做艺术指导。** 世界本身来自真实材料，没必要补造岛屿、海洋、路网或人格叙事。应改变绘制语言，而不是为了好看改变真实坐标。
8. **本轮不建议批准最终审美 Gate。** 支持继续使用现有产品，但建议先完成一次明确、受控的视觉迭代，再决定发布。工程测试通过并不等于作品感通过。

下文数值是**方向稿起始参数**，不是证明过的最佳值。应以同一真实文本、同一地图坐标、同一视口进行前后对照后锁定。

## 三、保留、降级与重做

### 必须保留

- 完整真实文字、稳定出处、全部标签；公平选书与有限路径不改。
- 暖纸底和深墨正文的基底；宋体正文与无衬线工具信息的分工。
- 真实封面决定书籍色彩；地图不按主题做彩虹分类。
- 世界地图独立入口、单 Canvas、语义列表双轨。
- 原生 select、明确关闭、返回保留现场；不要用视觉定制抵消原生能力。
- 无装饰引号、无卡片墙、无自动播放、无大书封拼贴。

### 删除或显著降级

- 地图总览中的常驻方格；它目前提供的工程感大于方向价值。
- 每一个地图标签都带纸色矩形的统一处理；这让地名像批量贴上的注释。
- 页面标题前后重复解释同一件事的 kicker、统计和辅助语句。
- 小径初始界面中占据独立大块位置的算法节奏切换。
- 相邻重复横线；同一页不必为每次语义转换都画一道线。
- 非交互文字上的按钮式包围。Local 标记必须保留，但无需始终占一个独立的 pill 行。

### 系统性重做

1. 顶部框架与首屏预算。
2. 三种空间的栅格：阅读页、目录页、地图页。
3. 小径目录的浏览节奏与当前小径的位置标记。
4. 地图的密度、等高线、点、标签四层绘制语言。
5. Book Aura 的面积、浓度与归属规则。

## 四、视觉北极星：推荐「可漫游的私人图集」

### 三个真实不同的方向

| 方向 | 构图与字体 | 色彩 / 地图 / 控件 | 优势与风险 |
| --- | --- | --- | --- |
| A. 私人图集 | 阅读页如图集中的正文页；窄正文、宽页边；目录像索引；地图像展开的跨页。宋体阅读、无衬线注释 | 纸面中性，书籍色限定于边缘与出处；真实密度地形；工具贴边而不环绕世界 | 最能统一文字与地图。风险是过度加入编号、装饰坐标，做成假地图 |
| B. 当代阅读室 | 文字在更紧凑、居中的阅读柱中；书房具明确书籍标识，标题更少 | 光集中在书籍来源区域；地图为独立安静场景；工具极少 | 亲近、适合长读；地图可能继续像附加模块，独特性较弱 |
| C. 个人出版物 | 更大胆字号对比、非对称版心、章节型目录，主动作像页边批注 | Aura 可作为少量较实的局部色面；地图占整页；控件融入编辑版式 | 身份强、分享一致。风险是杂志策展感过强，压过随机和真实材料 |

**选择 A，以 B 的阅读舒适度为约束，不混搭三种方向的装饰。**

北极星不是“做一张古地图”，而是：

> 一处文字是一页，一条线索是页边入口，一本书留下自己的色温；退远一步，所有文字成为同一个地形。

只建立三项签名：

- **共同版心**：出处、线索、操作沿同一阅读基线组织，而不是三个互不相关的条带。
- **书籍色标**：在出处旁、书房页边、地图点、分享卡中使用同源色，但各自不同强度。
- **当前位置**：小径名和地图选区使用同一种短墨线 / 活跃标记，不在普通阅读页铺地图纹样。

## 五、系统参数与首屏预算

### 1. 栅格：同一家族，不是同一个宽度

- 桌面外框仍可保持约1160px。
- 阅读版心采用约760–880px；长文进一步限制为约26–28个汉字宽。不要把所有正文都拉到外框宽。
- 目录允许完整外框宽，但用列与对齐消化宽度，而不是让计数漂在远处。
- 地图可比阅读版心宽，明确是一次尺度变化。
- 移动20px边距可以保留；不要为“更满”压缩到小于16px。

### 2. 字体：先修比例，再决定是否引入字体文件

当前系统宋体有阅读基础，但不同平台的字面、笔画和 fallback 差异会直接改变气质。先记录 Windows / macOS 实际渲染字体，再比较系统宋体与一款授权明确、本地托管的中文宋体；不要直接接入外部字体 CDN。

建议方向稿：

| 角色 | 桌面 | 移动 |
| --- | --- | --- |
| 短句 | 40–44px / 1.55–1.65 | 29–32px / 1.6–1.7 |
| 中句 | 30–34px / 1.7–1.8 | 25–27px / 1.7–1.8 |
| 长句 | 24–26px / 1.8–1.9 | 21–23px / 1.8–1.9 |
| 空间标题 | 24–28px | 22–26px |
| 出处与工具 | 13–14px | 13–14px |

不把所有行距统一缩紧。当前问题不是“字号都太大”，而是标题、定义、算法控件和正文之间的预算失衡。

### 3. 移动导航

保留六个显式入口与世界地图独立地位。390px 的“五个入口一行、关于孤零零一行”显得偶然。

优先方向稿：品牌一行，导航固定三列两行，行高44px；去掉品牌区与下方状态的多余垂直间隔。它不是为了节省所有高度，而是建立有意的节奏。Local 标记与页面上下文同一行，仍明确可见。不改成隐藏多数入口的汉堡菜单。

地图标题、上下文和一个主要控制应在约240–300px内完成；200%与长字号允许自然增长，不用固定高度截断。

### 4. 控件规则

- pill 只用于明确主动作；年份筛选改为文字选项加 active 下划线或轻边线，不让每个年份成为小按钮岛。
- 工具使用紧凑矩形或文字，不加不同阴影语言。
- 地图图标当前视觉40px，下一轮统一至少44px命中区；小径节奏按钮同样核对。
- 13px以上可读辅助文字优先；不要靠10px解释文字弥补界面含义不清。

## 七、地图专项：从算法散点到可阅读的地形

### 1. 背景：去掉工程纸，不换成装饰纸

保留现有暖纸。总览取消方格，不加噪点、罗盘、经纬度、虚构海岸或背景星空。画布边缘与页面用留白或一条边界区分即可，不要上下每层都有线框。

密度自身承担空间，不靠背景格子解释坐标。若区域尺度需要方向参考，先测试仅在较大缩放下出现极淡参考线，而非总览永久显示。

### 2. 密度：让点先形成地形，再能被辨认

当前高频点、网格、折线叠加，视觉噪声频率过于接近。

保持同一4,663点、同一坐标与密度含义；绘制时将密度变为连续、低浓度墨面：从纸面到灰绿的轻缓过渡。以背景、低密度、高密度三层可辨而不硬分段为起点。不可为了画面均衡把点挪动或填充空白区域。

### 3. 等高线：降低阶梯感，但不伪造地理

当前64×40网格产生的折角可见。先比较同一密度场的插值等值线与现有折线；允许渲染层平滑，但需限制偏移，检查不出现自交、不越过明显空洞、不凭空连接分离区域。

起始方案只保留2–3级线：最外层较弱，主要密度边界略强。线宽约0.6–1px屏幕像素，避免每条线一样硬。若平滑仍显装饰，宁可减少等高线数量，不要手绘漂亮山峰。

### 4. 点：面积预算比亮度更重要

建议以CSS屏幕像素半径开始试验：

- 总览背景点约0.6–0.9px，保留全量绘制。
- 区域成员约1.2–1.8px。
- 当前点约2.5–3px，加清晰细环。
- 点亮一本书时不把所有点统一放大到当前点等级；约1.2–2px，并对高密集屏幕区域减小半径或降低不透明度。

不要按书划线数量改变选句概率。这里仅是绘制密度控制，不删除数据、不抽掉可达性，也不改变标签资格。

多标签双环优先在区域 / 近看时显示；总览没必要让用户同时解读每个点的标签数量。

### 5. 标签：像地名，不像注释贴纸

- 普通地名13–15px，当前区域16–18px；不按热度大小排名。
- 去掉普通标签统一矩形底板，试验1–2px纸色文字描边形成局部让位；当前区域可保留小面积底板，但无投影。
- 保持碰撞避让；桌面先试12–16个主地名，移动6–8个，放大再渐进增加。
- 不因减标签让小区域无法进入；全部56条在语义目录可达。
- 强制当前标签可见时仍检查与控制、边缘和详情的冲突。

### 6. 三个尺度必须有不同任务

**世界：看轮廓与方向。** 点弱、地名清楚、控制少；不要尝试一次读懂全部56个词。

**区域：理解成员在哪里。** 区域点加深，周边保留少量邻近地名，背景点降一级；视图保持区域足够占比，不把全部世界一直留着。fit padding 先试15–20%，对分散标签如实显示分散，不强画一个闭合领地。

**详情：读一句。** 当前点保留；桌面详情放在能避开焦点的边缘，宽约340–400px；移动使用画布之后的阅读段，不做遮住地图且又只能露两行的 bottom sheet。

移动打开详情后可将画布暂时缩为约240–300px的上下文视窗，再显示完整正文；关闭恢复原地图尺寸、viewport及来源位置。此方案必须作为状态原型验证，避免尺寸改变造成跳动，不直接按静态稿施工。

### 7. Book Aura：更清楚，不是更大面积

保留来自书封的色。书籍选择控件、来源色标、当前书点使用同源色；背景不整片变为强烈彩色。

对比集中书与分散书：分散书像细小灯点，集中书应像有层次的局部聚落，不能成为糊住地形的实色印章。允许由这些真实点产生很淡的局部密度色，但不画任意光晕、不将标签染成书色。

书名状态只需一行主要信息；小径列表折叠后置，避免选书后再把地图向下挤100–150px。保留原生select；去掉它比其他控件更明显的胶囊阴影，以边框、色标和focus反馈即可。

### 8. 控制：沿边放，不把地图装在工具栏下面

桌面页标题与书籍选择可以处于同一上缘，缩放按钮放在画布边缘的轻控制区，离地名有排斥区；不加传统GIS侧栏。

移动将书籍select保留在画布前的一行，辅助小字移除或并入说明；缩放 / 复位在画布下缘或紧邻其下方，保证44px目标，不盖住当前点和地名。百分比不是读者的主任务，可弱化到焦点 / 操作时反馈，屏幕阅读器仍可读状态。

### 9. 移动首屏必须按剩余空间设计

本轮实测画布起点约478px。下一版390×844默认字号目标：起点约240–300px；高度优先使用剩余可用视口约460–520px，而不是盲目固定72svh再叠加所有头部。

总览 fit 将主要真实点边界纳入画布，四边保留约8–12%呼吸，不依赖巨大上下留白制造“地形”。先保证完整形状可识别，再追求大。

320px、200%和动态地址栏允许自然增长；“首屏全图”不能成为裁剪文字或隐藏必要控件的硬约束。触摸画布与页面滚动交界需真机检查。

### 10. 动效：说明尺度，不展示引擎

- 世界到区域：单次260–360ms温和视图过渡；交互中断立即响应。
- 选书：200–300ms颜色 / 透明度变化，不先回到默认书色再切换。
- 岔路：正文不动，只变化当前线索。
- 详情：120–180ms透明度足够，不让整段文字飞入。
- reduced-motion直接落到目标状态，不自动平滑滚动，焦点与语义仍正确。

不做持续粒子、模拟旅行线路、脉冲呼吸、无目的视差。**世界感来自尺度连续性，不来自运动数量。**

## 八、三批实施计划

### Batch A — 阅读版心与界面减法

范围：导航、门厅、书房、小径房间、About、通用控件。

先做同一真实短 / 中 / 长文的1440与390方向稿；比较当前版与私人图集版，不更换随机内容来制造优劣。先不动字体资源、地图坐标或标签算法。

涉及：`page.css`、`stage.css`、`rooms.css`、`paths.css`、Nav及对应房间组件。

Gate：陌生读者先读句子而不是界面；长文可读；出处和主动作明确；移动顶部不是一串说明；键盘和返回现场不退步。

### Batch B — 地图作品化与详情抵达

范围：密度 / 等高线 / 点 / 标签层次、控制位置、移动视口、Book Aura、详情焦点与恢复。

先做三张使用完全相同布局的静态渲染对照：现状、去网格减底板、连续密度与平滑等值线。再选一版进入交互。不要同时重跑UMAP或修改标签，这会让艺术指导与数据变化无法分辨。

涉及：`MapCanvas.tsx`、`MapRoom.tsx`、`map.css`、必要的viewport与焦点管理；布局数据默认不改。

Gate：世界总览独立成立；集中书不成色块；手机首屏能识别世界；从列表打开详情立即能读到；关闭与Back恢复。

### Batch C — 目录节奏、分享与一致性收口

范围：小径目录、主题书架、所有书、分享外围、全站出口和微交互。

先比较小径单列渐进与双栏目录；不引入新公共家族、不加入搜索或推荐榜。分享卡只修比例和外围，不重新发明成功方向。

Gate：全56小径、130本书完整可达；目录不是无尽重复行；分享仍显示长文与全部标签；全产品具共同来源色标与当前位置语言。

每批单独截图、交互验收、回归和提交。用户先批准方向，再施工；本报告不自动授权上述方案。

## 九、最终审美 Gate

### 必须同时满足

- [ ] 同一真实划线前后对比，阅读意愿提升，而非只是背景变漂亮。
- [ ] 门厅、书房、小径和地图一眼能分辨空间角色，又明显属于同一产品。
- [ ] 灰阶看正文 / 地形仍是主角；彩色看Aura有明确归属，不是随机装饰。
- [ ] 390×844默认状态的地图不再从约478px开始；完整世界可识别，控制仍可达。
- [ ] 地图去掉文字标签后仍有连续、可理解的地形，而非网格上的散点；加回标签后不像一批贴纸。
- [ ] 集中 / 分散、浅 / 深、冷 / 暖至少六本真实封面样本中，Aura均可辨且不过曝。
- [ ] 短、中、最长正文；0 / 1 / 2 / 3标签；长书名与无封面均成立。
- [ ] 320、390、1440、200%与reduced-motion通过；真机触摸、Safari未测则明确保持未验收。
- [ ] 从地图列表打开详情、从点打开详情、关闭、Back都能解释“我在哪里”。
- [ ] 所有内容可达性不因目录减法或图层美化降低。

### 真实访客小型测试

邀请至少3位首次访客，不预先解释“房间、小径、世界”。观察30–60秒后问：

1. 你觉得这里是什么？
2. 下一步想做什么？
3. 点亮一本书后，你理解发生了什么变化吗？
4. 从地图打开文字后，知道怎样回到刚才的位置吗？
5. 哪个画面让你愿意停留，哪个画面像在操作工具？

这是定性发现，不是显著性实验，不以点击次数作为留存KPI。若访客主要记得按钮、目录和数字，而不是文字、书色与世界，审美Gate仍未通过。

## 十、最终建议

**不要再逐个控件做零散“精修”。批准一个主方向，再用三批重排整套视觉关系。**

优先级只有三个：

1. 让文字和地图更早出现，减少图前 / 文前的界面。
2. 让地图从算法输出转为经过艺术指导的真实地形。
3. 让书房、小径和目录具有各自构图，而不是只换标题。

这个项目不缺功能，也不缺克制。现在最缺的是：**敢于把少数元素做得明确、把其余元素真正退后。**
