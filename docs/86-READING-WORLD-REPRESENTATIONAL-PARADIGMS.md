# 86 — 阅读世界建模范式：从句子点云到情境、关系与变换

日期：2026-10-02（本机 UTC+8）。状态：**R-02 首轮历史假设；已被后续方法边界修正，未选生产算法，未改线上。** 不是理论发现、系统综述或新模型效果报告。

> **现行纠正**：Henry明确要可复制、标准化的已有划线挖掘，而非内容生成、Agent写问题或逐案策展。本文四种假设及A+D偏好保留为历史探索，不能当共识或施工方案；`Q`、人工读法/关系/场景未获批准。最新边界、集合对照/条件通路的实际数值复跑及尚未解决的结构匹配见`docs/87-REPRODUCIBLE-WORLD-MINING.md`。

本轮因此不以“更好的相似度/平面布局”为总目标。模型名称或宣称的能力不是方案质量依据；以是否改变了基本对象、关系及阅读动作，真实原文是否支持，是否提供阅读价值来判断。研究可以提出新表示/布局/本机算法；具体核心设计仍先文字讨论，再在完整真实站点本机实现，不制作孤立手感预览页。既有发布授权不延续为未来push许可；不默认新增远程模型、运行时AI、后台、遥测、人格分析或公开数据。

## 2. 对旧研究的诊断，不把历史一笔否定

复看`54`、`70`、`71`、`72`、`74`、`78`：过去确实试过高维、多视角、拓扑群、见证关系和图，而不是仅调UMAP参数；图文共视、真实点进出、读者选书对读等结果已进入完整产品。旧实验不是全无价值，现地图也不是因投影失真就无用。

但大部分研究仍先固定“每段文字一个向量/节点”，再寻找邻域、团、骨架或画法。由此容易优化可达性和几何，却不能回答**为何这一组文字值得一起读，读者穿行时改变了什么理解**。星座图/数量书岛缺有效信息的反馈尤其不能用更花哨的线和材质救回。

关键不是证明“单向量不可能表示复杂语义”。向量可能包含丰富信息；问题是本站尚未把**分歧、适用条件、视角改变、结构类比、多段联合意义**显式建模。一个全局标量邻近不足以直接说明这些不同关系。我们应把距离降为某一种候选证据，不再让它充当整个世界的定义。

这次有三个可打破的默认：

1. 基本单位必须是孤立句子 → 也可以是一个问题、一个情境化读法或一个多段阅读场景。
2. 所有关系都应变成同一种距离 → 也可以是有类型、方向、条件和原文依据的关系。
3. 整个世界必须有一张固定总坐标图 → 也可以是相互连接的局部语境，或由有意义的阅读动作组织的世界。

## 3. 学科问题怎样转成建模问题

以下只借明确的结构原则，不把论文在其他任务的效果移植成本站效果。文献核对程度见§9。

### 3.1 群论/几何学习：先问变换与不变性，再谈形状

Geometric Deep Learning [1]以几何、对称与结构解释学习的归纳偏置。对本站更有用的问题不是“如何把句子放进E8”，而是：**领域、叙述者、尺度或前提变化时，我们希望哪些结构仍可认出？哪些差异必须留下？**

例如跨域类比保留角色/机制而替换领域；从个人经验转到制度机制需要保留原文身份，却未必保留结论。严格的群需要可组合、可逆等结构；多数阅读转折缺逆操作，丢弃语境也不可逆。因此目前只提“部分结构映射/有条件变换”，不宣布已构造语义群。Back可逆是导航性质，不是语义群的证明。范畴/群胚若将来使用，也必须先明确对象、合法映射及组成规律，而不是给任意节点图换术语。

### 3.2 层论：局部读法、对齐条件，而不是单一总解释

Neural Sheaf Diffusion [2]给图的节点/边附上局部向量空间和映射；这是图学习研究，分类效果不是阅读效果。自然语言歧义研究[3]用更严格的形式处理解释分布/指代情境，范围不等于不同作者意见不一，更不能据此宣称划线有量子效应。

2026年的CANVAS [4]把艺术作品与文本的比较关系本身置于表示中心，区分历史、风格、内容等关系。本轮读取了介绍、方法相关章节；它仍是关系条件化的embedding训练/检索模型，**不是**本文要直接复制的产品方案，更没有证明适合中文划线。

我借用的原则：**同一原文在不同问题中可能承担不同阅读角色；局部比较必须说明在什么条件下可对齐。** 第一版可以完全用可追溯的关系记录，而不训练sheaf网络。若未定义空间、限制映射和相容条件，就只能称“受层论启发的情境模型”，不能声称实现数学层、计算上同调或检测思想曲率。

### 3.3 结构类比：相近的词不是唯一可走的路

Gentner的结构映射理论[5]区分对象表面属性与对象间关系，类比关注可对应的关系结构。这为“话题不近，但机制可对照”的阅读提供问题意识。实际文字有没有足够的角色/机制对应，仍需逐处核查，不能把“资源影响行动”“一切都有反馈”这样宽泛抽象当成功类比。

### 3.4 高阶网络：基本单位可以是共同起作用的一组

高阶网络综述[6]讨论不止成对的交互及hypergraph等表示。迁移到阅读的假设：一个问题可能由三段以上共同构成，单个最相似对子无法表达阅读场景的作用。

但“策展三段”不自动证明不可约高阶作用，hyperedge也不自动提供意义。必须比较整组、删掉一段、以及只读对子，到底是否出现独特信息。没有这样的证据，就用普通可读集合，不为了术语复杂化。

### 3.5 信息瓶颈：为任务保真，而非为点云形状保真

信息瓶颈[7]以保留关于目标变量的信息来定义压缩。本轮只借“保真须说明针对什么任务”：对读时不能丢掉关键限定条件、出处或叙事身份，只保住相似词和几何邻居。本站尚无可用的联合概率模型和独立任务测量，不估计互信息，不把类比写成已优化的信息论损失。

## 4. 四种真正不同的产品假设

它们不是建议在导航加四种模式，也不是已确认的界面；可分别否决，最终最多先追一个主体形式。

### A. 问题剧场：世界由尚未解决的问题组成

- **基本对象**：问题＋若干有条件的读法；真实片段作为可检查的材料，而非作者/Henry立场的代言。
- **关系**：不同前提、限定、叙事经验、可能的反例/对照；反驳必须指向同一范围的命题，不因情绪/用词不同就成立。
- **产品动作**：从一段文字进入它触发的问题，看到另一本书改变了哪个前提或观察对象。主要前进不是“再找更像的一句”，而是“换一个前提”“看另一个机制”；一次只给当前有真实支撑的轻动作，不每步考试式三选一。
- **视觉可能**：少数可读声音的舞台/有张力的场景；不必全量点云或论文知识图谱。
- **独特价值**：从知道“附近还有什么”转为看见“为什么放在一起，以及哪里不能混为一谈”。
- **判败**：只有主题名下的若干卡片；策展问题过宽；为了冲突制造假对立；必须听教程或做概念判断才能继续阅读。其构建成本可能使它退化为人工专题集，这是必须正视的风险。

### B. 结构迁移世界：道路表示一种可检查的类比

- **基本对象**：局部机制与角色对应，例如原文自身已经说明的“可见缺陷—及时处理—防止继续损害”。不是先把不同书全部压成共同抽象主题。
- **关系**：具体对应表、保留的关系和不适用部分；映射可能仅部分成立，通常不是双射，也不自动可组合。
- **产品动作**：“换一个领域，看看这种结构如何出现”；同时保留原文字句与对应位置。不生成作者没写过的跨域答案。
- **视觉可能**：同一骨架在两个真实情境中展开/变形，而不是从点A飞到点B。少量对应比海量关联线重要。
- **独特价值**：能发现词面和地理距离都掩盖的联系，潜在惊喜最大。
- **判败**：对应依靠研究者脑补；只用抽象词“系统/反馈/成长”；重命名近邻路线；领域替换导致原文含义丢失。此方向风险高，尚无本轮跨书正例。

### C. 组合世界：地点是一组共同产生问题的真实文字

- **基本对象**：带角色的阅读场景/超边，成员可跨书、跨Tag，同一句可参与多个场景。
- **关系**：共同构成问题，而不是所有成员两两相似。可有设问、经历、限定、反向情境等不同作用；小说也可以只作为叙事经验，不硬转成论证命题。
- **产品动作**：走进一个场景、读少量全文、沿一处真实共同材料进入另一个场景。读者不必理解hypergraph。
- **视觉可能**：少量可进入的场景及连接；边表示共享材料/明确转折，不表示观点相同。不是强制聚类后的小岛复活。
- **独特价值**：把“碎片库”变为可以形成阅读事件的世界；不要求一段只有一个归属。
- **判败**：只是新名字的Tag小径；删掉任一段没影响；过度策展或解释文字喧宾夺主。暂未确认三段以上不可替代的真实组合，不声称找到高阶意义。

### D. 情境变形世界：一句话没有唯一的语义地址

- **基本对象**：原文身份不变，它在不同问题/语境中的作用可变。只对有依据的局部情境建立映射，接受未能对齐的部分。
- **关系**：同一材料在不同框架中的位置/角色变化，以及有范围的情境转移。
- **产品动作**：读者站在同一段文字上，改变正在追的问题，例如从“如何阅读”转到“预设答案如何影响理解”；变的是可比较的材料与角色，而不只是画布投影。共享的原文作为可认的转场锚点。
- **视觉可能**：局部视图可展开/重新组织，也可不采用空间布局；稳定的是材料身份与返回，不承诺全局唯一地理距离。
- **独特价值**：把多重解释作为模型的一部分，不强求一张总地图同时忠实表达所有关系。
- **判败**：只重做cPCA/多视图embedding；让相同文字反复出现但无信息增量；转场失去方向感；必须选择专家“观察窗口”。

## 5. 我的主判断：先追A＋D的统一模型，B作为更激进的研究对手

暂定最值得投入的主假设是**可穿行的问题与情境世界**：把问题、条件和可追溯关系提升为核心，而不是立即训练更大的向量模型。A是它的直观阅读入口，D是它的表示原则，不是两个并列模式。

B是能产生不同发现的较高风险路线，适合拿来检验主假设是否仍只是在做主题分类。C先作为潜在的数据组合形式，不急于建第三套界面。如果没有超越原文对读的信息，允许整体放弃这轮提案，而不是用数学名词守住沉没成本。

这里没有确定世界必须变成严肃学习工具。已有产品轻松漫游的价值须保留；若新模型只让读者更费力、更像上课，即使数据关系精确也可能不该成为主体验。世界入口、首页、书架与小径如何分工，要在核心形式成立后重新从全站讨论，不把所有研究按钮塞入现行导航。

## 6. 最小表示草图：不依赖二维坐标，也不是已实施schema

可用以下工作对象讨论，不改`src/domain/types.ts`：

```text
H = 原文、出处、稳定highlight ID（不重写）
Q = 编辑明确提出的探索问题（不是作者引文、不是AI答案）
C = 该问题下比较所需的情境/范围/限定条件
I(h, q, c) = 有原文依据的暂定读法/角色；允许多种，允许未知
R = 有类型、方向、情境与原文span依据的关系记录
S = 多条材料及各自角色共同组成的阅读场景（可选）
T = 有明确保留/变化部分的情境转移或结构映射（部分定义）
V = 面向阅读动作的呈现；地图只是V的一种可能
```

旧流水线：`原文 → embedding → 坐标 → 按位置/近邻抵达原文`。

新假设流水线：`原文/来源 → 问题与有条件读法 → 可核对关系/场景 → 读者主动转变关注 → 真实文字及相应呈现`。

这是**底层模型替换候选**，不是给旧地图多加一层标签。Embedding可做本机候选召回，也可先不用，但它的rank不变成关系的定义。不存在“同Tag所以赞同”“邻近所以支持”“环路所以悖论”等捷径。

关系记录至少需区分：谁提出读法、引用哪些原文范围、关系在哪个问题下成立、哪些前提未确认、审阅状态。它们是研究层/潜在新契约，不把解释写进当前public snapshot，也不把草稿关系假扮已审核Topic Tag。公开交付什么字段将是后续产品/审核决定，不能直接导出私有note/置信度/原始推理。

文体不能被抹平：小说人物发言、叙事描绘、转引、作者论证并不相同；有些文字适合意境或叙事联系而不适合论证角色。不要为全量覆盖把每段硬塞进Q/R；不进入新关系网的划线仍须通过书房/目录/既有入口全量可达。

## 8. 后续研究怎么做，避免另一轮漂亮空图

### 下一阶段建议：先检验表示，再定完整站点的核心形式

1. 固定当前公开语料与代码基线，保存输入/脚本指纹；新模型与旧地图均可作为候选，不把生产坐标当永久研究限制。
2. 拓展少量事前问题/机制及正反案例，优先包括不同文体、同词不同义、不同词同结构、真条件差异、无法建边的孤立片段。不要求Henry做批量标注；Agent承担逐条原文依据，明确非独立。
3. 分开比较A/D的条件读法与B的结构对应；同时保留现版普通对读、同书/同问题的简单材料组作为对照。先看有没有超出“我也能随便把两段摆在一起”的解释价值，不按cosine给自己颁奖。
4. 对关系做证据审查和扰动：删掉关键限定条件是否使关系失效，换入同词但不同机制的原文能否拒绝，保留原义的表达差异能否仍对应，换书后是否靠模板硬套。扰动只用于研究，不改写任何对外原文或制造假摘录。
5. 给出一个能用自然动作描述的核心体验与全站角色分工。文字共识后直接在**现有完整网站本机**做真实可运行版本，不用隔离小样让Henry预判手感；旧地图保留可返回的对照。再看顺畅、可发现的动作、美感和阅读意愿，不以新重型访客/手工评分Gate拖延探索。

### 判断尺度

- **关系依据**：片段有没有实际支持关系，限定/叙述身份是否被保留；不评“Henry思想正确”。
- **信息增量**：能否看出具体的条件差别或结构对应，超出仅显示另一句原文。这个问题需要实际比较，不因文案解释多就算成功。
- **自然性**：不会数学术语的人能读、能走、能回去；没有频繁多选模式/教程负担。
- **阅读吸引力**：是否想继续，是否保留轻松、美感和意外发现。精确但像作业也可能失败。
- **生产成本**：关系组织是否可维护，哪些需要局部人工策展；不以高覆盖掩盖脑补。
- **技术边界**：全量可达、稳定ID/出处/返回、手机/键盘/读屏退路、低DOM、无运行时模型与私有泄漏；生产整合和发布仍分别决定。
