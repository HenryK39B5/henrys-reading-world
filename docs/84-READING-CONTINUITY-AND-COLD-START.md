# 84 · 地图比例连续、对读停驻与公开冷启动

日期：2026-10-01。本轮为 Henry 授权的现有完整站点开发优化，不是独立样本、内容补标或发布。**本机工程候选收口；未 push / 部署。** 真机体验由 Henry 在另行确认发布后观察和反馈；不把浏览器仿真写成真机验收。

## 授权与本轮设计

Henry 认可先处理阅读稳定性、地图交互连续性及开发阶段能处理的冷启动/跟手开销，要求先解决已发现的可处理问题再发布。本轮不再让他选择实现细节，不开启新的模型研究；「按证据做内容审核」留到发布后讨论，不追求补齐所有 Topic Tag。

1. **比例连续**：保留逻辑 zoom 与 3.5 倍阅读阈值。手机从总览收成短图时裁切观看窗口，不再同时缩小地图地理比例；地图中心相对于窗口中心保持不变，而不是承诺每个点固定在整页同一个屏幕位置。
2. **主动对读停驻**：普通阅读随地图移动更新。读者点选另一本书后，保留当时的真实窗口、①②全文、候选书与稳定 ID；移动/缩放不再用相机相等判断清掉②。可换选同一选定窗口的其他书；「看地图当前位置」明确结束停驻，收起②也恢复跟随。回总览清除停驻。不是收藏、跨设备保存或第二套自动漫步。
3. **详情往返**：停驻内容在详情期间仍保留隐藏/inert DOM；返回恢复组合与原 opener 的焦点。收起后若原书按钮不再存在，焦点退回地图，不落到已脱离 DOM 的节点。
4. **开销收口**：避免固定尺寸手势重复重设 Canvas backing store；公开 HTML 解析时启动单次真实静态 JSON 请求，应用复用结果且仍做原来的 visibility/schema/内容验证。

## 实现与真实边界

- `src/domain/map.ts` 增加 presentation-only `scaleBasis` 与统一 `mapScale`。`MapCanvas.tsx` 中一个不可见 CSS 尺寸参照复用总览宽高规则；世界地图、其阅读窗口和未选书/Tag的详情共用参照。投影、逆投影、拖动/双指/滚轮、点命中、地名与实际查询一致，不通过补偿 zoom 偷换阈值或倍率含义。`MapStudyTerrain.tsx` 把 CSS 像素参照换成 backing-store 像素后供 WebGL 与 Canvas 等值带共用。
- 标签入场/避让计划取总览参照尺寸，而非收合中的短图尺寸；实际绘制与命中只平移/裁切。固定相机不因阅读栏打开而换入场名单。选中 Tag/Book 与 `__MAP_STUDY_ENDPOINT__` 不使用这个比例参照；研究仍走原画法。
- **圆内范围没有被伪装成不变**：短图中的圆仍由实际 `min(width,height) × 0.39` 绘制，查询使用同一投影。因此手机窗口收短后，实际圈到的地图范围和书/句数量会变小；择句仍是现有圆内/二维真点最近规则，不是 embedding 相似。停驻后的统计与候选明确属于「刚才这片」，不是新相机的实时统计。
- 固定比例揭露旧全方形相机 padding 对外缘不适用：公开真实最外侧点包括 `h-015` (y350)、`h-3944` (y9593)、`h-2300` (x350)、`h-3085` (x9650)。世界相机允许中心靠近边缘但仍限制在 0–10000；标签区域保留既有约束。抵达与刷新均保持真实外缘点可读。不是移动点位或生成地形。
- `useMapView.ts` 只保存 centerX/centerY/zoom，不把设备 CSS 尺寸存进 sessionStorage；外围世界中心刷新后不再套回旧 padding。
- `MapRoom.tsx` 内停驻只属于本次挂载期间的交互状态；**完整刷新不会保存①②组合**。相机仍按既有 session 规则恢复。没有加入账号、收藏或持久化内容功能。
- `vite.config.ts` 的 public-only HTML bootstrap 指向与 `?url` 相同的 fingerprinted JSON，部署 base 前缀经过深书房入口验证。单次请求解析结果可被开发 StrictMode 的两个消费者复用；拒绝、HTTP错误、解析失败诚实保持 error，不暗中重试，不消费 local scope。无 private/studio/research bootstrap、模型请求、遥测或新依赖。
