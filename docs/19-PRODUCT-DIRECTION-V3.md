# 19 — Product Direction V3：房间、小径与阅读世界地图

> 日期：2026-09-18
>
> 状态：**用户已确认的 V3 顶层产品方向；Batch 0 权威文档。** 本文件先于 `docs/17`、`docs/10`、`docs/12` 适用；旧文档保留为历史，冲突处由本文件及 `docs/20–22` 取代。

> 当前阶段只完成方向、规格、视觉与施工计划，不在 Batch 0 修改 schema、生成 embedding、打标签、导出 public snapshot、创建 repo、push 或部署。

## 1. 产品命题

Henry's Reading World 不以追求竞品差异化为第一目标。它的首要目标是：

> **把 Henry 在微信读书留下的真实划线，组织成一个适合阅读、重遇、探索与对外分享的个人阅读世界。**

差异化可以自然产生，但不能替代产品判断。产品继续坚持：

- 只使用 Henry 自己的真实微信读书划线；
- 不接入公众号、随想、课程或其他来源；
- 不做阅读数据 Dashboard、人格画像、CTR 推荐、传统社交或 AI 总结 Henry；
- 文字始终是体验中心；
- 情绪价值来自内容、排版、空间、色彩、路径与偶然性，而不是营销文案或功能堆叠。

## 2. V3 的一句话定义

> **一个由书籍房间、主题书架、思想小径和阅读地图组成的可漫游阅读空间。**

V2 已经建立“随便看看 / 主题书架 / 一本书”的房间体验。V3 新增逐条划线的主题标签，使访客可以沿明确的概念跨书探索，并在世界地图上观察全部划线形成的地形。

## 3. 空间语法

| 数据概念 | 产品中的空间含义 |
| --- | --- |
| Book | 房间 |
| Book Theme | 街区 / 主题书架 |
| Highlight | 房间中遇到的一处文字 |
| Topic Tag | 线索 |
| 同一 Topic Tag 下的划线 | 小径 |
| 带多个 Topic Tag 的划线 | 岔路口 / 山口 |
| embedding 生成的整体布局 | 世界地形 |

Book Theme 与 Topic Tag 是两层不同语义：

- **Book Theme** 回答“这本书大体放在哪个书架”；仍属于 Book，保留现有 14 个主题书架。
- **Topic Tag** 回答“这处划线涉及哪些概念”；属于 Highlight，一条可有 1–3 个地位平等的标签。

这项决定明确取代 `docs/10` 中“主题只属于 Book、Highlight 不做逐句主题”的限制，但不恢复人格策展、质量评分或 Opening / Contrast / Surprise。

## 4. 一种体验，两个数据范围，一个本地工作室

不建设两套彼此分裂的消费者产品。V3 使用同一个 Reading World 体验，由数据范围区分 public 与 local，并由独立 Studio 负责内容生产。

### 4.1 Public World

未来公开站点读取经过正式审核的 public snapshot：

- 当前已确认的书籍与划线范围为 108 本公开、22 本排除、6 条单条排除；
- public snapshot 仍为空，V3 稳定前暂停 Release-B；
- 公开标签、标签分配与地图也必须经过新增审核；
- 不提供全文搜索、AI 搜索、编辑、管理、登录、远程后台或运行时模型。

### 4.2 Local World

`dev:local` 使用完整 local-only snapshot：

- 130 本、4,663 条真实划线；
- 与 Public World 共用门厅、书房、书架、小径、地图、分享预览等消费者体验；
- 可以访问未公开书籍和划线；
- local-only 分享继续明确标注仅本机，不暗示已公开。

Henry 日常可以直接使用未来公开网页；只有需要完整私人范围时才进入 Local World。

### 4.3 Local Studio

Local Studio 是本机内容生产与出版工具，不是公众管理员后台：

- 标签词表、定义、合并、改名与审核；
- embedding 生成、模型评测、缓存、离群与一致性检查；
- 分批逐条标签建议与复核；
- 全文 / stable ID / 书名 / 标签搜索；
- 地图布局诊断与版本比较；
- publication policy、public preview 与正式导出 Gate。

它继续只绑定 `127.0.0.1`，不进入 public bundle，不建设登录、数据库或远程同步。

## 5. 顶层信息架构

公开主导航保持克制：

```text
随便看看
主题书架
主题小径
所有书
关于
```

推荐稳定房间：

```text
/                   门厅 / 随便看看
/themes             主题书架
/themes/:themeId    主题房间（Book Theme scope）
/paths              主题小径列表
/paths/:tagId       小径房间（Topic Tag scope）
/map                 世界地图（从主题小径模块进入，不必占一级导航）
/books              所有书
/books/:bookId      书籍房间
/about              关于
```

`/paths` 提供“小径列表 / 世界地图”两个入口；地图拥有稳定 URL，但不需要成为全站一级导航。

## 6. 五种核心循环

### 6.1 门厅

```text
遇见一句 → 查看来源和线索 → 再来一句
                         ↘ 进入书房 / 沿小径走
```

门厅仍保留现有按书公平随机，不使用 embedding 把它改成隐藏相关推荐。

### 6.2 书籍房间

```text
进入一本书 → 有限随机、不重复 → 完成一轮 → 明确重开
                                      ↘ 在地图中点亮这本书
```

现有 Release-A 有限书轮继续成立。

### 6.3 主题书架

Book Theme 继续提供粗粒度书籍街区；不声称当前句子语义属于书架主题。

### 6.4 主题小径

```text
选择线索 → 跨书公平遇见划线 → embedding 调整语义跳跃 → 完成一轮
```

小径主线由人工标签明确限定；embedding 只在硬约束之后改善呼吸节奏，不产生第二套“类似划线”功能。

### 6.5 世界地图

```text
观察整体地形 → 选择主题山峰 / 点亮一本书 → 放大区域 → 打开划线
```

地图既是可操作导航，也是产品视觉与情绪价值的重要组成部分，但小径列表始终提供完整、清晰、可访问的替代入口。

## 7. 岔路语义

一条拥有多个 Topic Tag 的划线是明确岔路口。

用户在某条小径中点击另一个标签时：

1. 当前划线保留在屏幕上；
2. 当前小径上下文切换到新标签；
3. 当前划线作为两条小径的交叉点；
4. 用户下一次点击“继续沿着……”才离开；
5. 浏览器 Back 恢复原小径、原句、轮次与必要滚动 / 地图位置。

所有标签地位平等，不设置公开或内部的“核心标签 / 连接标签”。一条划线可以天然属于两个同样重要的主题。

## 8. embedding 的角色

embedding 是私有编辑与布局基础设施，不是公开产品中的第二套内容入口：

- 建立覆盖面更好的标签发现样本；
- 辅助归纳、合并与拆分标签；
- 为逐条标注提供候选标签；
- 检查跨批次一致性、离群点、漏标和潜在岔路；
- 生成稳定的高维语义关系与世界地图地形；
- 在小径先公平选书之后，辅助控制“近 / 中 / 远”的语义跳跃。

V3 暂不做：

- 独立的“类似划线”推荐入口；
- public 或 local 的 AI 搜索；
- AI 问答；
- 运行时调用 embedding / LLM；
- 自动生成 Henry 的思想总结或人格画像。

厂商选择以免费额度、低成本、中文真实语料“够用”为原则，不追求榜单极致。具体评测属于 Batch 1。

## 9. 分享

分享绑定 stable highlight ID，继续以当前视觉中心为对象。V3 新要求：

- 页面显示该划线的全部 Topic Tag；
- CSS 分享卡片显示全部标签，自然换行、自然增高，不截断、不显示 `+N`；
- 复制纯文本携带全部标签；
- 公开深链落地后可沿任一标签进入小径；
- local-only 仍禁止 Web Share、上传或暗示本机 URL 已公开。

标签数量的内容规则仍建议通常 1–2、最多 3；这是语义质量约束，不是为了迁就卡片视觉。

## 10. 视觉重新设计的定位

V3 允许并要求重新审视全产品外观。审美不是发布后的抛光，而是产品体验本身：

- 划线回顾类产品的一屏一句与分享卡片已是基础能力；
- Reading World 必须通过排版、空间、地形、Book Aura 与路径反馈提供足够情绪价值；
- 不复制 flomo 或其他产品的视觉皮肤；
- 不退化为 Dashboard、标签云、卡片瀑布流或通用 AI 渐变；
- 文字仍是每个房间的第一视觉中心，地图是世界尺度的例外中心。

完整视觉方向见 `docs/21-V3-VISUAL-DIRECTION.md`。

## 11. 明确非目标

- 不接入微信读书以外的内容来源；
- 不做多用户产品、登录、云端私有空间或公众编辑；
- 不做点赞、评论、关注、收藏排行榜或运营留存机制；
- 不做阅读时长 / 数量 Dashboard；
- 不做 AI 人格分析、自动观点总结或生成文字冒充 Henry；
- 不把 embedding 向量、API key、账号标识或原始回包字段放进 public snapshot；
- 不因地图一次画出点而同时渲染 4,663 段文字；
- 不在 V3 内容与视觉 Gate 前恢复 Release-B 导出。

## 12. V3 成功标准

- 访客一眼理解标签是可进入的线索，而不是装饰元数据；
- 小径主线清楚，岔路转换不让当前上下文突然消失；
- 跨书公平继续优先，embedding 带来变化但不制造隐形策展叙事；
- 主题标签有中等抽象度、清晰边界和跨书连接价值；
- 世界地图同时具备作品感、可操作性、移动端降级与无障碍替代；
- 点亮一本书能自然揭示它如何分布在不同主题中；
- Public World 对访客成立，Local World 对 Henry 自己也成立；
- Local Studio 支持规模化内容生产而不污染消费者体验；
- 视觉重构提升情绪价值，同时保持长文本、键盘、reduced-motion 和真实内容优先。

## 13. 发布状态

已有公开内容决定继续有效：108 本公开、22 本排除、6 条单独排除，`reviewComplete=true`。V3 不重新打开这些决定；但正式导出前新增：

1. 标签词表审核；
2. 标签分配抽样与低信心审核；
3. public map 布局与视觉审核；
4. 分享卡片全部标签审核；
5. schema 3、public bundle 与历史泄漏扫描。

因此 Release-B 暂停，待 `docs/22` 中 V3 Batch 1–7 完成并由用户批准后恢复。
