# 05 — 界面、交互与视觉规格

## 1. 页面骨架

```text
轻量品牌                              随机 / 书 / 主题 / 关于

          当前真实划线（视觉中心）
          书名 · 作者 · 可选模糊年份
          再来一句 ↻     分享
          [点击书名后原位展开出处]

向下：书籍 → 主题 / 问题 → 年份筛选 → About / 收录范围
```

首屏没有头像大图、书架瀑布流、统计卡、人格结论或大型书封。只有本机模式才显示必要的 `仅本机 · 待公开审核` 状态，不能用精致设计掩盖隐私状态。

## 2. 视觉默认值

通过 CSS tokens 集中管理，可依据真实中文截图微调：

- 背景 `#FAF9F6`，主文字 `#252522`，次文字 `#66645E`，线条 `#DEDCD5`，克制强调色 `#425A4B`。上线前用工具核对实际对比度，不凭色值声称已满足 WCAG。
- 舞台字体：`"Songti SC", "STSong", "SimSun", serif`；UI：`system-ui, "Microsoft YaHei", sans-serif`。字体实际可用性按本机 / 手机验证，不联网下载整包中文字体。
- 主内容最大宽约 1120px；句子行宽约 26–32 个汉字（中大篇幅），桌面不拉满屏；移动边距 20–24px。短句在 1120px 容器内约 22 字/行，这是“字号更大”与行宽的取舍，已选择字号优先。
- UI 正文 16px；辅助文字不低于 14px；交互点击区至少 44×44 CSS px。
- 无 Card 大阴影、玻璃渐变、巨大引号、书封背景、花体和“灵魂邂逅”装饰性文案。

## 3. 长度与布局

按去空白后的 Unicode 字符数分档，只用于排版，不改写原文：

| 文本 | 桌面字号范围 | 移动字号范围 | 行距 |
| --- | --- | --- | --- |
| 1–40 字 | 28–46px | 28–32px | 1.7 |
| 41–120 字 | 24–38px | 23–27px | 1.8 |
| 121 字以上 | 20–30px | 20–24px | 1.9 |

字号上限是实测调的：52px 下 22 字句子会在 1120px 容器里断成 20+2 的“孤字成行”，降到 46px 后单行排完，同时行宽仍落在可接受范围。短句与中句用 `text-wrap: balance` 消除末行孤字，长句用 `text-wrap: pretty`（行数多时 balance 效果反而差）。改动前后均用真实数据在浏览器里实测行数、字号与横向溢出，见 docs/08。

使用 clamp 适配，长句不缩成小字，不用 line-clamp 或省略号截断舞台内容。超过一屏就自然滚动。保留 `white-space: pre-wrap`；不手动插 `<br>` 调漂亮；对极长英文串用 `overflow-wrap` 防溢出。

舞台保留稳定 min-height（桌面约 60–68svh，移动约 62–70svh），而非固定 height；换到长句允许必要增长，不裁剪。控件和出处不要跟着短句上下弹跳。短屏 / 横屏宁可可滚动，不强塞入视窗。不要让首次文本因动画空白等待 1.5 秒。

若真实数据没有某长度或换行样本，应报告覆盖缺口，不写临时假句调样式。

## 4. 换句状态机

idle → exiting（160ms）→ 原子换文 → entering（280ms）→ idle。

- 操作立即给按下反馈；转场时按钮保持焦点，使用 `aria-disabled=true` 并在处理器同步拒绝新请求。
- busy 期间快速点击全部忽略，不排队、不延长动画、不叠层；最多一个 pending quote。
- 正常转场仅一个文本节点 / 一份可读 DOM。旧 / 新元素重叠渲染若有使用，旧层必须对辅助技术隐藏。
- reduced-motion 时无淡入淡出，立即更新；不强制等待，也不触发平滑滚动。
- 转场期间出处 / 分享 / 列表跳转应有确定行为：分享暂不可用；明确选择另一条取消当前 pending 转场，立即显示所选记录。不得出现“复制了下一句却显示上一句”。
- 卸载清理计时器，标签页后台恢复不播放过期动画序列。
- 用独立 `aria-live=polite` 简短提示“已换一句，来自《书名》”；不要把整页设为 live，也不自动抢焦点到句子。

## 5. 出处层

书名是明确 button（可下划线 / 展开图标），作者始终可见，不依赖 hover。

- `aria-expanded`、`aria-controls` 指向邻近的非模态区域。
- 展示真实封面或书名占位、书名作者、可选审核简介、`这里收录了 N 处划线`。
- 按钮：`再看一处`、`查看这本书`、`收起`。
- `再看一处` 仅同书，保持展开；本书只一条或全看过时禁用并解释，不暗中换到别的书。
- `查看这本书` 选择下方书籍详情并滚动 / 聚焦标题，不做整页跳转；返回随机入口明确。
- 全局换句关闭出处；同书换句保持出处。收起按钮被移除时焦点回到书名按钮。
- 书封不可加载时展示真实书名排版框，不显示 broken image，不抓取网络素材补齐。

## 6. 阅读世界

- 书籍区显示约 4–6 本当前收录书，更多用 `查看全部收录书籍`，无无限瀑布流。
- 若按年份排序，称 `最近留下的划线`，不要把划线时间误称最近读完时间；缺年份项放末尾。
- 书详情展示本快照全部相关划线，可折叠长列表；选某条返回舞台时保留明确出处。
- 主题是可理解的短标题 / 问题，不是 AI 总结。本机开发可先使用基于原文的策展建议，在私有审核表记待复核，公开前再确认。每主题先呈现 2–4 条，优先每本书一条；更多才补同书。
- 年份筛选同一区域生效；空交集解释并提供清除筛选，不填推荐伪结果。
- About 只放用户确认的短介绍；未提供 bio 则省略，用 `这里收录了……` 解释真实范围。不写推测人格。
- 数据在深层作为普通小字 / 单行事实，不做成 KPI 卡片。

## 7. 时间标签

只从已审核 year 派生：当前年 `今年的一次划线`、上一年 `一年前`、2–5 年 `来自 N 年前`、更久 `很久以前的一次划线`。缺 year 就不显示时间。只知道年份时不声称“最近几天”。

用于计算的当前年通过时间函数注入；单元测试固定时间，不随着现实跨年随机失败。仅有年份时，年份差是近似表达，不展示精确年龄。

## 8. 分享与复制

“分享”打开小型 modal dialog，固定打开时的记录：

- `复制文字`：原文 + 换行 + `——《书名》作者` + 站点名；不改写 / 美化引用。
- `复制链接`：稳定 `h` ID 链接，见技术文档；本机地址提示仅本机有效。
- `卡片预览`：4:5 editorial typography，句子主角，出处和角落品牌。
- 不依赖 Web Share API / Clipboard 一定可用；Clipboard 失败时显示可选文本与手动复制提示，不能先显示成功 toast。
- 可选系统分享仅 public 模式，用户明确点击才调用；取消视为取消，不报“分享失败”。

卡片使用 CSS 预览即可，不承诺下载 PNG。短中句保持 4:5；长文本若无法在可读字号下完整放入，则扩高并提示“长文预览已延长比例”，禁止裁掉原文或无限缩小。二维码、封面提色和第三方图片生成服务不做。

dialog 有标题、初始焦点、Esc 关闭、焦点限制，关闭回原触发按钮；可用原生 `<dialog>` 并补浏览器测试。不因打开分享自动写剪贴板。仅本机模式禁用可传播链接 / 外部分享，卡片附 `仅本机 · 待公开审核`。

## 9. 空状态与错误

| 情况 | 行为 |
| --- | --- |
| 无获授权数据 | `尚未准备可展示的真实划线`；开发环境解释审核阻塞，无假数据 fallback |
| 全局一条 | 正常展示，换句不可用并说明 |
| 全部已看 | 新 cycle，可轻提示 `从读过的句子中再看一处`，不能卡死 |
| 数据结构非法 | 安全错误状态 + 开发诊断 ID，不泄露原文 / 请求响应 |
| ID 无效 | 轻提示后正常 Opening，不白屏 |
| 无书封 / 简介 / 年份 | 省略或真实书名占位，不编造 |
| 复制失败 | 可手动选取的文字 / URL，诚实提示 |
| 主题无交集 | 空列表说明和清除筛选 |

## 10. 最低人工检查

360×800、390×844、768×1024、1440×900，外加 320px 窄屏和 200% 缩放。键盘 Tab / Shift+Tab / Enter / Space / Esc 完整可走通；焦点可见、文字对比度符合 WCAG AA、无横向溢出、系统 reduced-motion 生效。

所有截图只用真实已授权内容。截图不再限制外发（用户已确认开发阶段内容可自由传输）；为不污染仓库仍放在 `.private/review/`。
