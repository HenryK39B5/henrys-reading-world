## 0. 为什么重开方向

7A 提升了阅读版心、房间比例和移动首屏，但用户仍认为现有外观“不错、尚不惊艳”，地图尤其缺乏顶级视觉品质。本轮不再把 7B 简化为去网格、减标签底板和修等高线；先问一个更根本的问题：**世界、书籍与一句真实文字是否具有同一视觉作品的三个距离？**

当前产品代码停在 `3b127a8`。本轮未改变产品代码、public snapshot、数据、地图布局、标签、公平算法或坐标。

## 1. 固定材料与对照方法

- 同一 `.private/local-snapshot.json`：4,663 个地图点、56 个标签锚点、64×40 原始密度场；

- 同一亮书 `b-013`（531 处），与同一地图详情 `h-013`（完整真实划线与 3 个现有 Topic Tag）；
- 三套样式 × 世界 / 点亮书 / 详情 × 1440×900 / 390×844，共 18 张截图；

- 密度面只是用现有密度栅格双线性插值后的**展示层**。即使改为不画等高线，全体真实点仍绘制；标签名不是区域边界。

## 2. 三套方向及直接判断

| 方向 | 构图与地图 | 强项 | 目前不能接受的弱项 |
| --- | --- | --- | --- |
| A · 浅纸陈列 | 暖纸、收敛版心、低浓度地形、少数地名；去掉网格，沿用少量原始轮廓线 | 真实形状清楚，中文与原阅读页自然相接；390px 的地图起点约 180px | 仍接近“更雅致的现有地图”；轮廓线还可被当作假海岸；不足以回应颠覆性期待 |
| B · 墨色世界 / 纸上抵达 | 深墨画布，浅点构成地形；桌面左地图、右信息；详情成为完整暖纸阅读面 | 从远景进入一条原文的材质对比最明确；地图与文字第一次具有显著距离感 | 深色点场很容易被误读为星图；暗场对比和深色长时阅读没有验证；单独采用会与现有暖纸房间割裂 |
| C · 跨页出版 | 桌面地图与阅读面形成展开的左右页；地图无方格、无轮廓，真实点与密度本身成形 | 世界和一句话在同一个画面中相互证明，而不是地图上面叠一个工具条；桌面文字是具有重量的作品组成部分 | world 状态的真实 `h-013` 是**固定样本预览**，并在地图标出对应点，不能成为产品默认“精选句”；390px 退化为普通上下结构；地图颗粒感尚未达到惊艳标准 |

重要纠偏：初版密度场有由栅格边界形成的显眼矩形，且 C 的等高线可被误读为海岸；实验第二轮只在静态绘制层柔化密度栅格边缘，并移除 C 的轮廓线。所有真实点仍保留；不假装点云自身绝无数据边界。B 亮书点采用与既有 `b-013` Book Aura 接近的色值做方向示意，**本静态脚本没有重新采样封面颜色**，不能作为最终色彩来源验证。

## 3. 审美结论，不伪装成验收

**没有一套已达到“顶级设计”完成态。**本阶段完成的是三套真实数据的可比方向，不是投票选一个现成皮肤。

初步选择：**以 C 的“世界与文字是展开的一本书”作为空间命题，单独检验 B 的“墨色地图 → 暖纸正文”作为材质变量。**这不是把 A/B/C 的装饰混搭；只保留一个交互签名——由点抵达完整原文，且返回仍在原位置。若暗场在 390px 看起来像星空，宁可维持浅纸地图，也不牺牲世界的真实与可信。

下一轮设计要解决的是结构，而非再微调 0.2px 点半径：

1. 世界总览：地图自身首先成为画面；控制移到边界，但保留原生书籍选择器和可见入口。移动首屏以真实图形而不是状态文字开始。
2. 亮书：多点集中书仍呈颗粒，不成为色块；至少六本真实浅/深、冷/暖、聚集/分散书封再比较。主题不分配彩虹语义色。
3. 抵达：列表入口与 Canvas 入口分别验证焦点、滚动、Back 与来源恢复；原文不截断。静态 C 的“默认固定一句”**不能**直接作为消费者策略。
4. 可读性：在同一跨页结构中对比浅图与暗图；灰阶、低对比屏幕、320px、200%、reduced-motion、键盘均需验证。
5. 地形边界：密度栅格与点云的硬边缘应被如实解释，不能美化成虚构大陆或暗示 Topic Tag 具有互斥地理边界。

## 4. 尚未验证的东西

- 18 张 PNG 是静态画面；其中导航、书籍提示与“靠近”文字不是可用按钮，**不能**声称通过键盘、读屏、焦点、Back、触摸、缩放或性能验收。
- 尚未在产品内对照当前地图的完整世界→区域→详情旅程；地图详情从语义列表进入是否立即可见仍需单独复核。
- 静态原型的局部文案是界面说明；引文、书名、作者、标签都来自固定真实 snapshot，不存在生成的假作者或假摘录。
- 没有验证跨平台中文字体、Safari、真机触摸或真实首次访客。
