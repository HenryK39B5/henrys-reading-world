## 3. 两种建模工具仍然各能做什么

### 3.1 集合对照：两组已有材料的联合对应

输入是两组真实划线及计算权重，成本取现有embedding的候选接近程度，求非负耦合矩阵。与逐句独立最近邻相比，分配受双方集合共同约束；不平衡模型允许偏离边缘权重，但所输运质量（mass）不是相似概率/覆盖思想百分比。

产品原先想探究：从当前阅读进入另一处材料，观察对应是集中还是分散、是否有多个可并读候选、在集合背景中是否稳定。**不是比较两本书完整思想体系，也不是生成共识/反驳解读。** 如果只是机械分散候选，联合模型没有兑现产品价值。

### 3.2 条件通路：其他内容怎样参与候选连接

固定模型关联图，指定不重叠端点集合A/B，求先到B而非A的模型committor及净通量；当前无向可逆模型下用边权与势差计算净流。输入条件改变，观察函数改变，原文/出处不改变。

产品原先想探究：两处兴趣之外，哪些第三处材料/支路参与连接，换条件后线索如何变化。**不是思想因果链、必经论证、语义成长路线或用户真实阅读轨迹。** 居中的势值不等于有效桥梁，高通量也不等于值得读。

87试算的端点是整本书已有划线集合。随后Agent提议缩为两条原文，属于尚未验证的新输入粒度；尚未实现可读支路提取。不能把6个整书条件的数值控制当作单句交互已验证。

## 4. 原先的产品草案：双侧并读→条件展开（保留沿革，非默认方案）

Agent提出的场景：用户读到一处有兴趣，想在别的书里继续发现；不必先有研究问题。

拟议操作：

```
当前真实原文
  → 找另一处并读
  → 选择另一书（自选，或带真实原文预览的少量候选）
  → 左右两侧阅读、展开候选、换某侧原文
  → 对当前组合产生兴趣
  → 看这两处之外的其他原文/候选支路
```

- 集合对照以两书划线集合为背景，读某段时只显露整体对应的一部分；希望“沿一侧阅读，查看另一侧候选如何变化”，而非一份永远固定的相似推荐列表。
- 条件展开拟议固定两条当前原文，点开中间候选，关掉可回原处；保留一端、替换另一端时观察线索变化。
- 手机不强塞双列长全文；原文完整、出处/返回/同一ID保持一致。
- 候选书推荐、显示门槛、单句端点与支路提取均未实现/验证。不预先手选“应该搭配的两本书”，不加生成关系说明或自动播放路线。

**Henry随后对核心操作提出自然性异议：**算法需要两组输入，不等于用户有动机去选两组内容。若必须教完选A/选B/换端点流程才会用，就像研究工具。此草案因此退为历史/可选深入能力，不得再被默认当作下一轮主入口。

## 5. 最新探索方向：单点显露的关联世界

### 5.1 Henry提出的直觉

每条划线是向量空间中的点；根据距离或其他规则建立联系，形成网络。选中一点，显示其连接的其他点；用户自己选择下一处，继续漫游。空间可为2D/3D或其他形式，并不先限定技术栈。

地球仪想象：把点放在球面，当前点的关联点亮起，转动球体抵达其他地方。Henry明确这只是抛砖引玉，并希望继续brainstorm其他形态。

### 5.2 Agent据此提出的体验语法（仍待讨论）

```
进入世界，并看到一条真实原文及其对应点
  → 当前点的少量关联候选显露
  → 在选择前能预览真实文字/出处
  → 读者主动点选另一处
  → 新原文出现，新的候选显露
  → 可回到已读原文与原探索现场
```

不是先给空图让用户猜点是什么，也不是只亮几个点让人逐个碰运气。图形提供可去方向，真实文字帮助判断是否想去；全文仍以原样阅读。不生成解释，不强迫两端点、不让模式菜单或算法参数成为前置任务。

希望获得的增量：从分散在不同书的材料中，看见少量有计算依据、可预览、可抵达的阅读旁路。来源可以核查，关系留给读者判断。**这只是价值假设，不是已证实阅读收益。**

### 5.3 把四层分开

| 层次 | 职责 | 不能混淆为 |
| --- | --- | --- |
| 关联网络 | 用固定方法产生稀疏的模型关联候选 | 作者互相引用、赞同/反对、确定语义 |
| 空间布局 | 给节点安排位置，尽量还原结构且便于浏览 | 屏幕相邻必定在原空间相近 |
| 视觉表现 | 整体质感、材质、光照、可辨重点与连续变化 | 高度/亮度自动代表知识质量或思想深度 |
| 阅读交互 | 选择、预览、读全文、继续、返回 | 算法替读者选好下一句或安排必经故事 |

显式backlink来自真实记录中的引用；本轮类比的是操作语法，我们的边是模型候选，不能伪装成实际引用。一张网络可用多种空间形式，不能因视觉喜欢球面就宣称原关系已经适合球面。

## 6. 三种视觉候选

### A. 阅读地球仪——稳定、可转动的整体

**起源：**Henry的球面灵感；具体操作与“优先视觉假说”是Agent提案，不是用户已选方案。

- 初始有原文与明确的球面对应点；少量关联候选亮起，附可读的真实预览/书名。
- 用户转动、靠近、主动选择；更换当前原文后更新候选，不每次重排整个球面。
- 不默认画全网线海，仅显露当前/正在查看关系的少量线。背面候选需球缘方向提示或可读入口，而非要求盲目旋转寻找。
- 审美可研究材质、表面质感、光照、层次发光和转动—停驻—阅读的连续性；不凭空生成“思想大陆/地名”。

**价值假设：**给人愿意进入的整体对象，并可能形成稳定位置记忆；这是待验证的体验，不是所有访客天然会懂。背面遮挡、密集区文字/点击、手机和原文焦点稳定是主要风险。

**布局约束：**球壳仍是二维曲面，放入3D显示仍需降维。不能以均匀撒点加漂亮关联光代替关系布局验证；关系计算留在原空间，球面尽量还原并记录错位。

### B. 焦点透镜——局部清楚，整个世界仍在周围

**起源：**Agent候选，未选择双曲或普通透镜技术。

- 当前区域被放大、可以读；远处压缩为周围参照。
- 点另一处使该部分进入焦点，保留可返回的整体；倾向稳定底层布局与视图变化，而非每步重排一团候选。
- 可研究普通焦点透镜或双曲几何。双曲表示/H3涉及层次假设，不能据原论文成功就保证本站成立，也不能为用工具人为造主题树。

**价值假设：**免去地球背面遮挡，可能更适合连续阅读且保留世界感。风险是焦点移动造成方位丢失、画面变成普通科研关系图，或数据结构根本不适合该几何。

### C. 可展开的阅读曲面——先看局部，再展开具体材料

**起源：**Agent次级候选，更依赖分组依据。

- 远看为具有空间质感的整体；进入一处时局部展开，显露真实材料与跨区候选。
- 区域必须来自材料关系，不能按书籍数量/ID拼岛，不能强塞落单句子，也不为群手写漂亮主题名。
- 不拿装饰地形/更多连线掩盖信息不足；材质可以是审美选择，但不能被暗示为未经检验的语义分区。

**价值假设：**避免访客精确点击大量微小节点。风险是既有“单点海/巨块/尺度不稳”、不可核查边界及书岛式无意义聚合。目前优先级低是Agent判断，并非Henry否决。

三种形态都未产生新样板/截图。记录它们是为了后续讨论，不要求Henry现在从隔离样本预判手感，也不决定新菜单、命名、导航或地图替换。

## 7. 随机过程可以藏在单点操作后面

Agent补充的工具候选：从当前节点出发、带重启的随机游走/个性化PageRank，让扩散围绕当前原文计算关联强度，不要求访客再指定终点。

- 一跳邻居与多步扩散候选必须区分，后者不能画成真实直接边。
- 可先把直接邻域做得可读，再检验扩散是否增加信息；并非已决定替换87的模型或首页公平抽句。
- 注意泛用高连接节点、同书/少书循环、词面相似、漂移、孤点；分数不是观点一致/阅读价值/作者引用。
- 规则/参数/输入指纹仍可复跑，不用Agent逐案写关系或手工挑漂亮材料。无模型关系就保持空/未知，不为奇观补边。
- 只借用数学定义，不建议引入Neo4j数据库、远程服务或公众运行时模型；本轮没有实施该算法。

## 8. 审美、自然性和信息价值必须共同设计

Henry明确审美和fancy效果对吸引使用非常重要，不应把视觉降为技术完成后的附加装饰。Agent据此提出：材质/空间深度/有控制的显露与真实阅读一起设计，而非先做数据图最后加发光。

仍须保护：真实完整划线/出处/ID、原语境与返回、长文/小屏/键盘/低动态退路；不创建数千DOM按钮或同时铺全文；不把高维向量或私有理由送入正常消费者产物。视觉装饰不必逐像素映射语义，但有语义承诺的点/边/区域必须有依据。

旧71/72失败是反例，不是永久禁止网络、3D或新的本机布局，也不是球面已经优于旧地图。已发布第二版继续作为有效对照，用户对其真机的认可不自动成为新候选的Gate。

## 9. 留给后续讨论的核心问题（不是新增人工任务）

1. 用户能否从第一眼的真实原文和对应点，自然理解并选择另一处，而不用教学A/B设置？
2. 在选择前给什么真实预览，才不只是亮点/书名的盲逛？读完候选是否多得到一份愿意看的内容？
3. 稳定地理位置与当前局部阅读焦点如何兼顾？是否真的需要球面，还是其他空间形态更自然？
4. 哪种统一规则产生少量可读关联，怎样处理孤点、重复、泛用句和弱关系？不逐案策展。
5. 若用球面，怎样呈现背面关系、密集区域与布局失真而不打断阅读？若用透镜，怎样不丢方位？
6. 更多点线/漂亮材质是否带来真实信息，还是只是效果？不要把算法名词/工程通过作为答案。
7. 集合对照与双端点条件通路是否应仅作可选深入能力，或暂不进入产品？数学工具可保留，不因投入过试验就要求前台使用。

不把上述问题改成Henry批量评分/内容创作或新的独立首次访客硬Gate。先文字共同确定核心设计，再按既有约定直接在现有完整网站本机运行真实demo并优化，不制作隔离手感样板。此处没有开始该实现阶段。

## 10. 前轮来源与数学澄清归档

- Goldberg、Hollender，*The Hairy Ball Problem is PPAD-Complete*：https://arxiv.org/abs/1902.07657 。毛球定理约束球面连续切向向量场必须有零点；有限节点铺球面/连边并不直接满足该条件，所以不能据此证明必有无法放点的位置，也不否定地球仪灵感。若以后真的做连续切向流场，才可能成为相关约束。

- 个性化PageRank数学定义参考Neo4j作者维护的GDS文档：https://neo4j.com/docs/graph-data-science/current/algorithms/page-rank/ 。仅参考方法，不引入其产品/服务。
